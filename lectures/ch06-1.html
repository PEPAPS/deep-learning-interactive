6 · Deep feedforward networks

What is a feedforward network?

A network \(f(\mathbf x;\boldsymbol\theta)\) is a composition of layers: \(f=f^{(3)}\circ f^{(2)}\circ f^{(1)}\). Information flows forward from x to y; there are no feedback loops. Training adjusts θ so that f ≈ the target function f*.

\[ \mathbf y=f(\mathbf x;\boldsymbol\theta)\approx f^*(\mathbf x),\qquad f(\mathbf x)=f^{(3)}\Big(f^{(2)}\big(f^{(1)}(\mathbf x)\big)\Big) \]

In plain words

  • Feedforward: x → intermediate computations → y, no feedback connections. (With feedback they become recurrent networks, Lecture 11.)
  • Network: many functions composed; the model is a directed acyclic graph. \(f^{(1)}\) is the first layer, \(f^{(2)}\) the second … the last is the output layer. The chain length is the depth — hence “deep learning”.
  • Training data give noisy examples of f*(x) with labels y ≈ f*(x). They say what the output must be, but not what the other layers should do — those are hidden layers.
  • Neural: loosely inspired by neuroscience. Each hidden layer is a vector; its dimension is the width; each element is a unit (like a neuron) that takes many inputs and computes its own activation. But the goal is function approximation for generalization, not modelling the brain.

Calculation, step by step

  1. One hidden unit with weights w = (0.5, −1), bias b = 0.2, input x = (1, 2).
  2. Pre-activation \(z=0.5\cdot1+(-1)\cdot2+0.2=-1.3\). ReLU: \(h=\max\{0,-1.3\}=0\).
  3. Parameter count for 2 → 3 → 1: layer 1 has \(2\times3\) weights + 3 biases = 9; layer 2 has \(3\times1+1=4\); total 13.

6 · From linear models to networks

Linear models are limited — so learn the features

A linear model can’t capture interactions between inputs. Apply it to features φ(x) instead. Deep learning’s strategy: learn φ from data with a hidden layer: \(y=\boldsymbol\phi(\mathbf x;\boldsymbol\theta)^\top\mathbf w\).

In plain words

Linear and logistic regression are attractive: they fit efficiently and reliably (closed form or convex optimization). But they can only represent linear functions. Fix: use a non-linear transformation φ(x) — a new representation of x. How to choose φ?

  1. Generic φ (e.g. the infinite-dimensional one implicit in an RBF-kernel machine): enough capacity to fit the training set, but based only on local smoothness → often generalizes poorly on hard tasks.
  2. Hand-engineer φ: dominant before deep learning; decades of expert work per domain (speech, vision) with little transfer.
  3. Learn φ: \(y=f(\mathbf x;\boldsymbol\theta,\mathbf w)=\boldsymbol\phi(\mathbf x;\boldsymbol\theta)^\top\mathbf w\). Gives up convexity, but can be as generic as (1) and lets humans encode knowledge by choosing the family φ(x; θ), not the exact function — like (2).

Terms on this slide

Feature map φ
A function that turns raw input x into new features.
Representation
How the input is described to the next stage.
Kernel trick
Use a very high-dimensional φ implicitly, through similarity computations.
Convex
Bowl-shaped loss: any local minimum is global. Neural nets lose this.

Calculation, step by step

  1. Point x = (0.3, 0.4). Hand-made features \(\boldsymbol\phi=(x_1^2,x_2^2)=(0.09,0.16)\).
  2. Linear model in feature space: w = (1, 1), b = −0.5: \(0.09+0.16-0.5=-0.25<0\) → “inner disk”.
  3. Point (1, 0.2): φ = (1, 0.04) → \(1.04-0.5=0.54>0\) → “ring”. The boundary \(x_1^2+x_2^2=0.5\) is a circle in x-space, but a line in φ-space.

6.1 · Example: learning XOR

XOR: the smallest problem that needs a hidden layer

No line separates XOR. One hidden layer with ReLU maps the 4 points into a new space where a line does — the network learns a better representation.

\[ J(\boldsymbol\theta)=\frac14\sum_{\mathbf x\in\mathbb X}\big(f^*(\mathbf x)-f(\mathbf x;\boldsymbol\theta)\big)^2 \](6.1) MSE on the 4 points \[ f(\mathbf x;\mathbf w,b)=\mathbf x^{\top}\mathbf w+b\ \Rightarrow\ \mathbf w=\mathbf 0,\ b=\tfrac12 \](6.2) best linear model: 0.5 everywhere \[ f(\mathbf x;\mathbf W,\mathbf c,\mathbf w,b)=\mathbf w^{\top}\max\{0,\mathbf W^{\top}\mathbf x+\mathbf c\}+b \](6.3) \[ \mathbf W=\begin{bmatrix}1&1\\1&1\end{bmatrix},\ \mathbf c=\begin{bmatrix}0\\-1\end{bmatrix},\ \mathbf w=\begin{bmatrix}1\\-2\end{bmatrix},\ b=0 \](6.4–6.6)

In plain words

  • XOR(x₁, x₂) = 1 when exactly one input is 1. Here we only care about fitting the 4 points (no generalization), using MSE to keep the math simple (MSE is usually not right for binary data).
  • If \(f^{(1)}\) were linear, the whole network \(\mathbf x^\top\mathbf W\mathbf w\) would be linear. So use an affine transformation followed by a fixed non-linear activation: \(\mathbf h=g(\mathbf W^\top\mathbf x+\mathbf c)\), with ReLU \(g(z)=\max\{0,z\}\) — the modern default.
  • After \(\mathbf X\mathbf W+\mathbf c\) all points lie on a line where the output must go 0 → 1 → 0 (impossible for a linear model). ReLU bends that line, and the points become linearly separable.
  • We just wrote down the solution. In practice gradient descent finds one (often a messier, equivalent one) — and the result depends on the initial weights.

Terms on this slide

XOR
“Exclusive or”: 1 if exactly one input is 1.
Activation function g
Fixed non-linear function applied element-wise.
ReLU
Rectified linear unit \(\max\{0,z\}\).
Linearly separable
A straight line (hyperplane) can split the classes.

Calculation, step by step (all 4 points)

  1. \(\mathbf X=\begin{bmatrix}0&0\\0&1\\1&0\\1&1\end{bmatrix}\Rightarrow\mathbf X\mathbf W=\begin{bmatrix}0&0\\1&1\\1&1\\2&2\end{bmatrix}\).
  2. Add c = (0, −1): \(\begin{bmatrix}0&-1\\1&0\\1&0\\2&1\end{bmatrix}\).
  3. ReLU: \(\begin{bmatrix}0&0\\1&0\\1&0\\2&1\end{bmatrix}\) — the two “1” examples now coincide at (1, 0).
  4. Multiply by w = (1, −2): \((0,\ 1,\ 1,\ 2-2)=(0,1,1,0)\) ✓ — zero error.

6.2 · Gradient-based learning

Training a network: non-convex, iterative, init-sensitive

Non-linearity makes the loss non-convex: no normal equations, no global guarantees. We use iterative gradient methods that drive the cost “very low”, and the result depends on the initial weights.

In plain words

  • Linear regression: solve linear equations. Logistic regression / SVMs: convex optimization with global convergence guarantees. Neural nets: SGD on a non-convex loss.
  • SGD on non-convex losses is sensitive to the initial parameters. Initialize weights to small random values (randomness breaks symmetry between units); biases to zero or small positive values.
  • Linear models are also trained with gradient descent when data is huge — so training a network isn’t that different; the gradient is just a bit more complicated (back-propagation, next lecture).

Terms on this slide

Non-convex
The loss surface has many valleys, plateaus and saddles.
Initialization
The starting values of all weights before training.
Symmetry breaking
Random init makes units start different, so they learn different features.
Dead ReLU
A unit whose input is negative for every example: output 0, gradient 0 — it can’t recover.

Calculation, step by step

  1. If all weights start at 0, every hidden unit computes the same value and gets the same gradient → they stay identical forever (symmetry). Random init avoids this.
  2. ReLU unit with bias 0.1 and small weights: for input x ≈ 0, \(z\approx0.1>0\) → active, gradient 1 flows.
  3. With bias −0.5 and small weights: \(z\approx-0.5<0\) → output 0, gradient 0 → a dead unit from the start.

6.2.1 · Cost functions

The cost function: negative log-likelihood

Most networks define \(p_{\text{model}}(\mathbf y\mid\mathbf x)\) and minimize the negative log-likelihood (cross-entropy). The output distribution decides the exact formula; the log keeps gradients large and predictable.

\[ J(\boldsymbol\theta)=-\mathbb E_{\mathbf x,\mathbf y\sim\hat p_{\text{data}}}\log p_{\text{model}}(\mathbf y\mid\mathbf x) \](6.12) \[ p_{\text{model}}(\mathbf y\mid\mathbf x)=\mathcal N\big(\mathbf y;f(\mathbf x;\boldsymbol\theta),\mathbf I\big)\ \Rightarrow\ J(\boldsymbol\theta)=\tfrac12\mathbb E\,\|\mathbf y-f(\mathbf x;\boldsymbol\theta)\|^2+\text{const} \](6.13)

In plain words

  • Cost functions for networks are the same as for other parametric models. Usually: the cross-entropy between training data and the model’s predictions.
  • Sometimes simpler: predict only a statistic of y (e.g. its mean) with a specialized loss.
  • Total cost = primary cost + regularization (e.g. weight decay, as for linear models).
  • Gaussian output → MSE (up to a factor ½ and a constant) — for any network f, not just linear ones.
  • Why NLL is good: saturating functions (very flat) give tiny gradients. Many output units contain an exp that saturates when its argument is very negative; the log undoes the exp.

Terms on this slide

Cross-entropy
\(-\mathbb E\log p_{\text{model}}\): the NLL averaged over the data.
Saturate
Become flat, so the derivative is ≈ 0.
Statistic of y
A summary such as the mean or median, instead of a whole distribution.

Calculation, step by step

  1. Gaussian with σ = 1, target y = 2, prediction f(x) = 1.5.
  2. \(-\log\mathcal N(2;1.5,1)=\frac12(2-1.5)^2+\frac12\log(2\pi)=0.125+0.919=1.044\).
  3. The 0.919 never depends on θ, so minimizing the NLL = minimizing \(\frac12(y-f)^2\) (the MSE).

  • Leads toRegularization terms added to the cost (L6).
6.2.2 · Output units

Output units, and the linear unit for real values

The output unit turns the last hidden features h into the parameters of p(y|x). For real-valued y: a linear unit gives the mean of a Gaussian → MSE loss, and it never saturates.

\[ \hat{\mathbf y}=\mathbf W^{\top}\mathbf h+\mathbf b,\qquad p(\mathbf y\mid\mathbf x)=\mathcal N(\mathbf y;\hat{\mathbf y},\mathbf I) \](6.17)

In plain words

  • The choice of cost is tightly coupled to the choice of output unit: cross-entropy + the output’s representation = the exact loss formula.
  • Any output unit can also be used as a hidden unit.
  • Linear units: affine transformation with no non-linearity. They output the mean of a conditional Gaussian; maximizing log-likelihood = minimizing MSE.
  • Linear units don’t saturate, so they pose little difficulty for gradient-based optimization.

Terms on this slide

Output unit
The final layer that produces the prediction / distribution parameters.
h
The features computed by the last hidden layer.
Conditional Gaussian
A bell curve over y whose centre depends on x.

Calculation, step by step

  1. h = (1, 0.5), W = (2, −1), b = 0.3 → \(\hat y=2\cdot1-1\cdot0.5+0.3=1.8\).
  2. Target y = 2: loss \(\frac12(2-1.8)^2=0.02\); gradient \(\partial L/\partial\hat y=\hat y-y=-0.2\) → push \(\hat y\) up.
6.2.2.2 · Sigmoid units for Bernoulli outputs

Yes/no outputs: sigmoid + log-likelihood

Predict \(P(y=1\mid\mathbf x)=\sigma(z)\). With the log-likelihood the loss is softplus((1 − 2y)z): it only saturates when the answer is already right, so wrong answers always get a strong gradient. MSE does not have this property.

\[ P(y=1\mid\mathbf x)=\max\{0,\min\{1,\mathbf w^{\top}\mathbf h+b\}\}\quad\text{(bad: gradient 0 outside [0,1])} \](6.18) \[ \hat y=\sigma(\mathbf w^{\top}\mathbf h+b),\qquad\sigma(x)=\frac{1}{1+\exp(-x)} \](6.19) \[ \log\tilde P(y)=yz,\ \ \tilde P(y)=\exp(yz),\ \ P(y)=\frac{\exp(yz)}{\sum_{y'=0}^{1}\exp(y'z)}=\sigma\big((2y-1)z\big) \](6.20–6.23) \[ J(\boldsymbol\theta)=-\log\sigma\big((2y-1)z\big)=\zeta\big((1-2y)z\big),\qquad\zeta(x)=\log(1+\exp(x)) \](6.24–6.26)

In plain words

  • Binary targets → a Bernoulli distribution, defined by one number in [0, 1].
  • Clipping a linear unit to [0, 1] is a valid probability, but outside that range the gradient is 0 → no learning signal.
  • The sigmoid unit = linear layer computing the logit z, then σ(z). σ saturates for very positive/negative z.
  • Softplus ζ is a smooth version of \(\max(0,x)\); range (0, ∞).
  • ζ((1 − 2y)z) saturates only when (1 − 2y)z is very negative, i.e. y = 1 and z ≫ 0, or y = 0 and z ≪ 0 — the model is right. When wrong, ζ(x) ≈ |z| and its slope → ±1: full-strength correction.
  • With MSE the loss saturates whenever σ(z) saturates — right or wrong. So maximum likelihood is almost always preferred for sigmoid outputs.

Terms on this slide

Bernoulli
Distribution over {0, 1} with P(1) = ŷ.
Logit z
Unnormalized log-probability; z = wᵀh + b.
\(\tilde P\)
Unnormalized probability (before dividing by the sum).
Softplus ζ(x)
log(1 + eˣ) — “softened” max(0, x).

Calculation, step by step

  1. True y = 1, but the network says z = −3: \(\sigma(-3)=0.047\) — confidently wrong.
  2. NLL \(=\zeta(3)=\log(1+e^3)=3.049\); gradient \(\partial J/\partial z=\sigma(z)-y=-0.953\): strong push up.
  3. MSE \((\sigma-1)^2=0.907\); gradient \(2(\sigma-1)\sigma(1-\sigma)=2(-0.953)(0.047)(0.953)=-0.086\): 11× weaker.

  • Builds onLogistic regression (L2): a sigmoid output on raw features.
  • Leads toLSTM gates (L11): sigmoids used as soft on/off switches.
6.2.2.3 · Softmax units for multinoulli outputs

Many classes: softmax

A linear layer outputs logits z; softmax exponentiates and normalizes them into probabilities that sum to 1. The log-likelihood \(z_y-\log\sum_j e^{z_j}\) has a term that never saturates; the gradient is simply p − onehot(y).

\[ \mathbf z=\mathbf W^{\top}\mathbf h+\mathbf b,\quad z_i=\log\tilde P(y=i\mid\mathbf x),\qquad\text{softmax}(\mathbf z)_i=\frac{\exp(z_i)}{\sum_j\exp(z_j)} \](6.28–6.29) \[ \log\text{softmax}(\mathbf z)_i=z_i-\log\sum_j\exp(z_j)\approx z_i-\max_j z_j \](6.30) \[ \text{softmax}(\mathbf z)=\text{softmax}(\mathbf z+c)=\text{softmax}\big(\mathbf z-\max_i z_i\big) \](6.32–6.33) invariance & stable form

In plain words

  • For n classes we need a vector ŷ with every \(\hat y_i\in[0,1]\) and \(\sum\hat y_i=1\).
  • Maximizing log softmax: the first term \(z_y\) pushes the correct logit up (can’t saturate); the second pushes all logits down. If the correct class already has the largest logit, the two terms roughly cancel → that example contributes little; training focuses on misclassified examples.
  • Losses without a log (e.g. squared error) fail with softmax: when it saturates, the gradient vanishes even for confident wrong answers.
  • Only differences between logits matter. A softmax output saturates to 1 when its logit is far above the others, and to 0 when another is far above it.
  • z has n entries but only n − 1 are needed (they sum to 1) — overparametrized, but simpler and works fine.
  • Softmax = competition (like lateral inhibition in cortex): one goes up, others go down; extreme case = winner-take-all. It’s really a soft argmax (“softargmax”).

Terms on this slide

Multinoulli
Categorical distribution over n classes.
Logits z
Unnormalized log-probabilities.
One-hot vector
1 at the correct class, 0 elsewhere.
Numerically stable
Avoids overflow: exp(1000) is infinite, but exp(0) is fine after subtracting the max.

Calculation, step by step

  1. Logits z = (2, 1, 0.1): \(e^z=(7.389,2.718,1.105)\), sum = 11.212.
  2. softmax = (0.659, 0.242, 0.099).
  3. True class 2: loss \(=-\log0.242=1.417\) (= \(-1+\log11.212=-1+2.417\)).
  4. Gradient \(=\mathbf p-\text{onehot}=(0.659,\;0.242-1,\;0.099)=(0.659,-0.758,0.099)\).
  5. Stable version: subtract max 2 → (0, −1, −1.9): \(e=(1,0.368,0.150)\), sum 1.518 → same probabilities.

  • Builds onClassification tasks (L1) and discriminative models (L2).
  • Leads toLabel smoothing (L6): softmax can never reach exactly 0/1, so we soften the targets. RNN outputs (L11) use a softmax at every time step.
6.3 – 6.3.1 · Hidden units

Rectified linear units and their generalizations

ReLU is an excellent default. It is almost linear, so the gradient is large and consistent (exactly 1) whenever the unit is active. Generalizations fix its one weakness: zero gradient when inactive.

\[ \mathbf h=g(\mathbf W^{\top}\mathbf x+\mathbf b),\qquad g(z)=\max\{0,z\} \](6.36) \[ h_i=g(\mathbf z,\boldsymbol\alpha)_i=\max(0,z_i)+\alpha_i\min(0,z_i) \]abs (α = −1), leaky (α = 0.01), PReLU (α learned) \[ g(\mathbf z)_i=\max_{j\in\mathbb G^{(i)}}z_j,\quad\mathbb G^{(i)}=\{(i-1)k+1,\dots,ik\} \](6.37) maxout

In plain words

  • Choosing hidden units is trial and error, checked on a validation set; ReLU is the safe start.
  • ReLU’s second derivative is 0 almost everywhere and its first derivative is 1 where active → no confusing second-order effects.
  • Initialize b to a small positive value (e.g. 0.1) so most units start active.
  • Drawback: no learning on examples where the unit is inactive. Absolute value (polarity-invariant image features), leaky ReLU, PReLU use a non-zero slope for z < 0.
  • ReLU isn’t differentiable at 0 (left derivative 0, right derivative 1). It doesn’t matter: training rarely reaches a point with zero gradient, software returns a one-sided derivative, and an exact 0 is usually a rounded tiny number anyway.
  • Maxout outputs the max of a group of k inputs: a learned, convex, piecewise-linear activation with up to k pieces; can approximate any convex function; k weight vectors per unit → needs more regularization.

Terms on this slide

Active unit
z > 0, so the ReLU passes z (and the gradient) through.
Left / right derivative
Slope just left / right of a point; equal ⇔ differentiable.
Piecewise linear
Made of straight segments.
Leaky / PReLU
ReLU with a small or learned negative slope.

Calculation, step by step

  1. z = (−0.5, 0.3, 2): ReLU → (0, 0.3, 2), slopes (0, 1, 1).
  2. Leaky (α = 0.01) at −0.5: \(0+0.01\times(-0.5)=-0.005\), slope 0.01 — still learns a little.
  3. Maxout with one group of 3: \(\max(-0.5,0.3,2)=2\); gradient goes only to the winner (third input).

  • Leads toDesigning models to aid optimization (L9): ReLU is a key reason deep nets became trainable.
  • Leads toHe / normalized initialization (L8), tuned for ReLU.
6.3.2 · Logistic sigmoid and hyperbolic tangent

Sigmoid and tanh: saturating units

Sigmoidal units saturate over most of their input range, which makes gradient learning hard — discouraged as hidden units. If you must, tanh is better than σ because it behaves like the identity near 0.

\[ g(z)=\sigma(z)=\frac{1}{1+e^{-z}},\qquad g(z)=\tanh(z),\qquad\tanh(z)=2\sigma(2z)-1 \]

In plain words

  • Before ReLU, most networks used σ or tanh hidden units.
  • They are only sensitive to their input when z is near 0; elsewhere they saturate high or low → tiny gradients.
  • As output units they’re fine if the cost (log-likelihood) undoes the saturation.
  • tanh(0) = 0 while σ(0) = ½. So a deep tanh network \(\hat y=\mathbf w^\top\tanh(\mathbf U^\top\tanh(\mathbf V^\top\mathbf x))\) behaves like the linear model \(\mathbf w^\top\mathbf U^\top\mathbf V^\top\mathbf x\) while activations are small — easier to train.
  • Sigmoidal units remain common in recurrent networks, many probabilistic models and some autoencoders, where piecewise-linear units are ruled out.

Terms on this slide

Saturation
The flat regions where g′(z) ≈ 0.
tanh
Hyperbolic tangent, range (−1, 1), centred at 0.

Calculation, step by step

  1. At z = 0: σ = 0.5, σ′ = 0.25; tanh = 0, tanh′ = 1.
  2. At z = 5: σ′ = σ(1 − σ) = 0.9933 × 0.0067 = 0.0066; tanh′ = 1 − tanh²(5) = 0.00018. Both ≈ 0: saturated.
  3. Check \(\tanh(z)=2\sigma(2z)-1\) at z = 1: \(2\sigma(2)-1=2(0.881)-1=0.762=\tanh(1)\) ✓.

Connections

  • Leads toRNNs (L11) use tanh hidden states; vanishing gradients (L7) come from multiplying many small slopes.
6.3.3 · Other hidden units

Other hidden units

Many differentiable functions work; new ones are only published if they clearly beat the standards. Some intuitive ideas (softplus) actually work worse than ReLU.

\[ h_i=\exp\Big(-\frac{1}{\sigma_i^2}\|\mathbf W_{:,i}-\mathbf x\|^2\Big)\ \ \text{(RBF)},\qquad g(a)=\max(-1,\min(1,a))\ \ \text{(hard tanh)},\qquad g(a)=\zeta(a)=\log(1+e^a) \]

In plain words

  • Softmax hidden units act as a switch over k options — used in architectures that learn to manipulate memory.
  • RBF: most active when x is near a template \(\mathbf W_{:,i}\); saturates to 0 for most x → hard to optimize.
  • Hard tanh: like tanh and the rectifier, but bounded.
  • Softplus: a smooth rectifier; one might expect it to beat ReLU (differentiable everywhere, saturates less), but empirically it doesn’t — so its use is discouraged.
  • Even \(h=\cos(\mathbf W\mathbf x+\mathbf b)\) reached < 1% error on MNIST.

Terms on this slide

RBF
Radial basis function: a bump centred on a template.
MNIST
Classic dataset of 28×28 handwritten digits.

Calculation, step by step

  1. Softplus(0) = log 2 = 0.693; ReLU(0) = 0. Softplus(5) = 5.0067 ≈ ReLU(5) = 5.
  2. Hard tanh(2.5) = max(−1, min(1, 2.5)) = 1; hard tanh(0.4) = 0.4.
  3. RBF with \(\|\mathbf W_{:,i}-\mathbf x\|^2=0.5\), σ = 1: \(e^{-0.5}=0.607\); at distance² 9: \(e^{-9}=0.0001\) — saturated.
6.4 · Architecture design

Architecture: layers in a chain, depth and width

One hidden layer can fit the training set, but deeper networks often use far fewer units and parameters and generalize better — at the price of being harder to optimize. Choose by validation error.

\[ \mathbf h^{(1)}=g^{(1)}\big(\mathbf W^{(1)\top}\mathbf x+\mathbf b^{(1)}\big),\qquad\mathbf h^{(2)}=g^{(2)}\big(\mathbf W^{(2)\top}\mathbf h^{(1)}+\mathbf b^{(2)}\big),\ \dots \](6.40–6.41)

In plain words

  • Architecture = how many units, and how they connect. Most networks: groups of units called layers, arranged in a chain.
  • Main choices for chains: depth (number of layers) and width (units per layer).
  • The ideal architecture is found by experiment, monitoring the validation error.
  • The demo shows the depth advantage: each layer “folds” the input; k layers with 2 ReLUs each make \(2^k\) linear pieces, which a single layer would need ~\(2^k\) units for.

Terms on this slide

Architecture
The overall structure: units and connections.
Chain structure
Each layer is a function of the previous layer only.
Linear region / piece
An input range where a ReLU network is exactly linear.

Calculation, step by step

  1. MNIST MLP: 784 inputs → 100 → 100 → 100 → 10 outputs.
  2. Parameters: \((784\cdot100+100)+(100\cdot100+100)\times2+(100\cdot10+10)=78\,500+20\,200+1\,010=99\,710\).
  3. Depth trick: 5 folding layers (10 ReLU units) give \(2^5=32\) linear pieces.
6.4.1 · Universal approximation properties and depth

Universal approximation: enough width can represent anything

With one hidden layer and enough units, an MLP can approximate any continuous function on a bounded region. But it may need an exponential number of units, and training may still fail or overfit. Depth makes the representation much more efficient.

In plain words

  • Theorem: a feedforward net with a linear output layer and ≥ 1 hidden layer with a “squashing” activation (e.g. sigmoid) can approximate any Borel-measurable function between finite-dimensional spaces to any non-zero error, given enough hidden units. Its derivatives can approximate the function’s derivatives too.
  • Practically: any continuous function on a closed, bounded subset of \(\mathbb R^n\) (and any function between finite discrete spaces). Later proofs cover ReLU too.
  • Representable ≠ learnable. Learning can fail because the optimizer can’t find the parameters, or because training overfits and picks the wrong function.
  • Worst case: one hidden unit per input configuration to distinguish → exponentially many.
  • Choosing depth expresses a belief that the function is a composition of simpler functions, or a multi-step program (intermediate outputs like counters/pointers). Empirically, greater depth generalizes better on many tasks.

Terms on this slide

Squashing function
Activation that saturates at both ends (like σ).
Borel measurable
A very broad class of functions; includes all continuous functions on bounded regions.
Representational capacity
What the network can express (vs. what training finds).

Calculation, step by step

  1. A 1-D ReLU network with k hidden units is piecewise linear with at most k kinks.
  2. Approximating sin(6x) on [0, 1] with straight segments: error drops roughly like 1/k² as segments shrink.
  3. A step function needs a near-vertical piece: with k = 100 units the error is small but never exactly zero (non-zero error is all the theorem promises).

Connections

  • Builds onComposition of factors (L2): the prior that depth encodes.
  • Leads toRegularization (L6): huge capacity must be controlled to generalize.
6.4.2 · Other architectural considerations

Beyond the plain chain: skip connections and sparse connectivity

Layers need not form a simple chain. Skip connections help gradients reach early layers; sparser connection patterns cut parameters and computation for specific problems.

In plain words

  • Many architectures have a main chain plus extras such as skip connections from layer i to layer i + 2 or higher. They make it easier for the gradient to flow from the output to layers near the input.
  • How to connect a pair of layers: the default (matrix W) connects every input unit to every output unit — fully connected.
  • Specialized networks connect each unit to only a small subset → fewer parameters, less computation, but the pattern is problem dependent (e.g. convolutional nets for images).

Terms on this slide

Fully connected (dense)
Every input unit is linked to every output unit.
Sparse / local connectivity
Each output unit sees only a few inputs.
Skip connection
A shortcut that bypasses one or more layers.

Calculation, step by step

  1. Fully connected 1 000 → 1 000 units: \(10^6\) weights.
  2. Local connections where each output sees 9 inputs: \(9\,000\) weights — 111× fewer.
  3. A skip connection adds the earlier layer’s output: \(\mathbf h^{(i+2)}=f(\mathbf h^{(i+1)})+\mathbf h^{(i)}\), so \(\partial\mathbf h^{(i+2)}/\partial\mathbf h^{(i)}\) contains an identity term that never vanishes.

  • Leads toSparse interactions in CNNs (L10), skip connections for optimization (L9), skip connections through time (L11).
