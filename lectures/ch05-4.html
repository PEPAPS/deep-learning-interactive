Where this lecture fits in training

This lecture explains where the loss function comes from (maximum likelihood, step 5) and gives us the language — bias, variance, error bars — to judge results in the evaluation step.

Loss = negative log-likelihood

Almost every loss you will meet (MSE, cross-entropy, softmax loss) is a negative log-likelihood. MLE tells us which loss matches which output type.

Regularizer = prior

MAP estimation shows weight decay is a Gaussian prior on the weights: “prefer small weights” becomes a probability statement.

Evaluation = statistics

A test error is itself an estimate with a standard error. Bias and variance explain the U-shaped curve of Lecture 1.

5.4.1 · Point estimation

Point estimators: a best single guess from data

An estimator is any function of the data that guesses an unknown quantity. Because the data are random, the guess \(\hat\theta\) is a random variable — draw a new dataset and you get a new guess.

In plain words

Point estimation = give the single “best” prediction of some quantity — one parameter, or a vector of parameters such as the weights of linear regression. We write the estimate with a hat: \(\hat\theta\).

Frequentist view: the true \(\theta\) is fixed but unknown; \(\hat\theta\) depends on the random data, so it is random. A good estimator is one whose output is usually close to the true θ.

Function estimation: if \(y=f(\mathbf x)+\epsilon\) (ε = the part of y not predictable from x), a learned model \(\hat f\) is just a point estimate in “function space”.

\[ \hat{\boldsymbol\theta}_m=g\big(\mathbf x^{(1)},\dots,\mathbf x^{(m)}\big) \](5.19)

Terms on this slide

\(\theta\)
The true parameter that generated the data (unknown).
\(\hat\theta_m\)
Our estimate computed from m examples.
Estimator / statistic \(g\)
The recipe (function) that turns data into the estimate.
i.i.d.
Examples drawn independently from the same distribution.
Bernoulli(θ)
A coin: value 1 with probability θ, value 0 with probability 1 − θ.

Calculation, step by step

  1. Ten flips: 1, 0, 0, 1, 1, 0, 1, 0, 0, 1.
  2. Estimator “fraction of heads”: \(\hat\theta=\frac{1+0+0+1+1+0+1+0+0+1}{10}=\frac{5}{10}=0.5\).
  3. Another ten flips from the same coin might give 3 heads → \(\hat\theta=0.3\). Same recipe, different data, different answer — that is why \(\hat\theta\) has a distribution (see the histogram).

  • Builds onLinear regression (L1): the learned weights \(\hat{\mathbf w}\) are a point estimate.
  • Leads toMinibatch gradients (L7): a minibatch gradient is itself an estimator of the true gradient, with its own variance.
5.4.2 · Bias

Bias: is the estimator right on average?

Bias = average guess − true value. Zero bias means: over many datasets, the errors cancel out. The sample mean is unbiased; the “divide by m” variance is biased (too small by σ²/m).

\[ \text{bias}(\hat\theta_m)=\mathbb E(\hat\theta_m)-\theta \](5.20) \[ \text{Bernoulli: } P(x;\theta)=\theta^{x}(1-\theta)^{1-x},\quad \hat\theta_m=\frac1m\sum_i x^{(i)}\;\Rightarrow\;\mathbb E[\hat\theta_m]=\frac1m\sum_i\mathbb E[x^{(i)}]=\theta \](5.21–5.27) unbiased \[ \hat\sigma_m^2=\frac1m\sum_i\big(x^{(i)}-\hat\mu_m\big)^2,\qquad \mathbb E[\hat\sigma_m^2]=\frac{m-1}{m}\sigma^2\;\Rightarrow\;\text{bias}=-\frac{\sigma^2}{m} \](5.36–5.40) biased \[ \tilde\sigma_m^2=\frac{1}{m-1}\sum_i\big(x^{(i)}-\hat\mu_m\big)^2,\qquad\mathbb E[\tilde\sigma_m^2]=\sigma^2 \]unbiased sample variance

In plain words

Unbiased: bias = 0. Asymptotically unbiased: bias → 0 as m → ∞ (the “divide by m” variance is asymptotically unbiased). The Gaussian sample mean \(\hat\mu_m=\frac1m\sum x^{(i)}\) is unbiased too.

Why is \(\hat\sigma^2\) too small? The deviations are measured from \(\hat\mu_m\), which is computed from the same points and therefore sits closer to them than the true μ. Dividing by m − 1 corrects for this.

Unbiased is nice but not always “best” — we often prefer slightly biased estimators with much smaller variance (next slides).

Terms on this slide

\(\mathbb E(\cdot)\)
Expected value: the average over infinitely many random datasets.
Unbiased
\(\mathbb E(\hat\theta_m)=\theta\).
Gaussian \(\mathcal N(x;\mu,\sigma^2)\)
Bell curve with mean μ and variance σ²: \(\frac{1}{\sqrt{2\pi\sigma^2}}\exp\!\big(-\frac{(x-\mu)^2}{2\sigma^2}\big)\).
Sample mean \(\hat\mu_m\)
Average of the data points.
Sample variance
Average squared distance from the sample mean.

Calculation, step by step

  1. Data: 2, 4, 6 (m = 3). Sample mean \(\hat\mu=(2+4+6)/3=4\).
  2. Squared deviations: \((2-4)^2+(4-4)^2+(6-4)^2=4+0+4=8\).
  3. Biased: \(\hat\sigma^2=8/3=2.667\). Unbiased: \(\tilde\sigma^2=8/2=4\).
  4. If the true σ² were 4, the biased version is expected to give \(\frac{m-1}{m}\sigma^2=\frac23\cdot4=2.667\) on average: bias \(=-4/3\).

Connections

  • Leads toBatch-norm running statistics (L9): BN estimates means and variances of activations from minibatches.
  • CompareUnderfitting (L1): a model with too little capacity is a biased estimator of the true function.
5.4.3 · Variance and standard error

Variance, standard error and confidence intervals

Variance measures how much the estimate would change if we resampled the data. Its square root, the standard error, gives error bars: SE of a mean = σ/√m.

\[ \text{SE}(\hat\mu_m)=\sqrt{\operatorname{Var}\Big[\frac1m\sum_{i=1}^{m}x^{(i)}\Big]}=\frac{\sigma}{\sqrt m} \](5.46) \[ \big(\hat\mu_m-1.96\,\text{SE}(\hat\mu_m),\;\hat\mu_m+1.96\,\text{SE}(\hat\mu_m)\big) \](5.47) 95% confidence interval \[ \operatorname{Var}(\hat\theta_m)=\frac{\theta(1-\theta)}{m}\quad\text{(Bernoulli)} \](5.48–5.53)

In plain words

We estimate generalization error by the average error on a test set; the number of test examples decides how accurate that estimate is. By the central limit theorem the average is approximately Gaussian, so “estimate ± 1.96·SE” contains the true value about 95% of the time.

We don’t know σ, so we plug in an estimate; \(\sqrt{\text{sample variance}}\) slightly underestimates σ, but for large m it is fine. Variance of popular estimators shrinks as m grows.

Terms on this slide

Variance \(\operatorname{Var}(\hat\theta)\)
Expected squared distance of the estimate from its own average.
Standard error SE
\(\sqrt{\operatorname{Var}}\): the typical size of the estimate’s random wobble.
Central limit theorem
Averages of many independent values are approximately Gaussian.
Confidence interval
A range built so that it covers the true value with a chosen probability (here 95%; 1.96 is the 97.5% point of a standard Gaussian).

Calculation, step by step

  1. Test set: m = 1 000 images, 80 mistakes → \(\hat p=80/1000=0.08\).
  2. \(\text{SE}=\sqrt{\hat p(1-\hat p)/m}=\sqrt{0.08\times0.92/1000}=\sqrt{0.0000736}=0.0086\).
  3. 95% CI: \(0.08\pm1.96\times0.0086=0.08\pm0.0168\Rightarrow[0.063,\;0.097]\).
  4. So “model A: 8.0% vs model B: 8.5%” on this test set is not a reliable difference.

Connections

  • Leads toMinibatch size (L7): the same σ/√m rule says a 100× bigger batch only gives a 10× more accurate gradient.
  • Builds onCross-validation (L1): used when the test set would be too small for tight error bars.
5.4.4 · Trading off bias and variance

The bias–variance trade-off

Expected squared error = bias² + variance. More capacity → lower bias, higher variance. The best model balances the two — this is the U-shaped curve of Lecture 1.

\[ \text{MSE}=\mathbb E\big[(\hat\theta_m-\theta)^2\big]=\text{Bias}(\hat\theta_m)^2+\operatorname{Var}(\hat\theta_m) \](5.54)

In plain words

  • Bias: expected deviation from the true value — systematic error (aiming at the wrong spot).
  • Variance: deviation from the expected estimate caused by the particular sample — random error (shaky aim).
  • Choose between a high-bias and a high-variance estimator by cross-validation, or by comparing their MSE, which includes both.
  • Linked to capacity: simple models (low capacity) = high bias → underfit; flexible models = high variance → overfit.

Analogy: darts

High bias = all darts land close together but left of the bullseye. High variance = darts centred on the bullseye on average but scattered everywhere. The total miss (MSE) counts both.

Terms on this slide

MSE of an estimator
Average squared distance between estimate and truth, over random datasets.
\(\mathbb E[\hat f(x)]\)
The average fitted curve (thick orange line in the demo).
Noise σ²
Irreducible error (the Bayes error) that adds to bias² + variance on new data.

Calculation, step by step

  1. Estimator A: bias 0.1, variance 0.04 → MSE \(=0.1^2+0.04=0.01+0.04=0.05\).
  2. Estimator B: bias 0 (unbiased), variance 0.09 → MSE \(=0+0.09=0.09\).
  3. A is better despite being biased — a small bias bought a big reduction in variance.

Connections

  • Builds onThe U-shaped curve (L1).
  • Leads toRegularization (L6): “trade increased bias for reduced variance” is the definition of a good regularizer; bagging reduces variance by averaging.
5.5 · Maximum likelihood estimation

Maximum likelihood: the principle behind most losses

Pick the parameters that make the observed data most probable. In practice: maximize the sum of log-probabilities — equivalently, minimize the cross-entropy (KL divergence) between the data and the model.

\[ \boldsymbol\theta_{\text{ML}}=\arg\max_{\boldsymbol\theta}\prod_{i=1}^{m}p_{\text{model}}\big(\mathbf x^{(i)};\boldsymbol\theta\big)=\arg\max_{\boldsymbol\theta}\sum_{i=1}^{m}\log p_{\text{model}}\big(\mathbf x^{(i)};\boldsymbol\theta\big) \](5.57–5.58) \[ =\arg\max_{\boldsymbol\theta}\ \mathbb E_{\mathbf x\sim\hat p_{\text{data}}}\log p_{\text{model}}(\mathbf x;\boldsymbol\theta) \](5.59) divide by m \[ D_{\text{KL}}\big(\hat p_{\text{data}}\,\|\,p_{\text{model}}\big)=\mathbb E_{\mathbf x\sim\hat p_{\text{data}}}\big[\log\hat p_{\text{data}}(\mathbf x)-\log p_{\text{model}}(\mathbf x)\big] \](5.60) → minimize \(-\mathbb E\log p_{\text{model}}\) (5.61)

In plain words

Rather than guessing an estimator and checking its bias and variance, maximum likelihood gives a recipe that produces good estimators for any model.

  • The product of many probabilities underflows to 0 on a computer; the log turns it into a sum without changing the argmax.
  • Dividing by m gives an average (an expectation over the empirical distribution \(\hat p_{\text{data}}\) of the training set).
  • The first KL term doesn’t depend on the model, so minimizing KL = minimizing cross-entropy \(-\mathbb E\log p_{\text{model}}\).
  • Any negative log-likelihood is a cross-entropy — MSE is the cross-entropy between the data and a Gaussian model.

Terms on this slide

Likelihood
Probability of the observed data viewed as a function of θ.
\(\arg\max\)
“The θ at which the expression is largest” (not the largest value itself).
Empirical distribution \(\hat p_{\text{data}}\)
Probability 1/m on each training example.
KL divergence
A non-negative measure of how different two distributions are (0 only when equal).
Cross-entropy
\(H(p,q)=-\mathbb E_{p}\log q\); the average “surprise” of q on data from p.
Underflow
A number too small for the computer, rounded to 0.

Calculation, step by step

  1. 7 heads in 10 flips. \(L(0.5)=0.5^{10}=0.000977\).
  2. \(L(0.7)=0.7^7\cdot0.3^3=0.08235\times0.027=0.002224\) — 2.3× larger, so θ = 0.7 explains the data better.
  3. Log version: \(\log L(0.7)=7\ln0.7+3\ln0.3=7(-0.357)+3(-1.204)=-6.109\).
  4. Cross-entropy example: data distribution (0.5, 0.5), model (0.8, 0.2): \(H=-(0.5\ln0.8+0.5\ln0.2)=0.916\); entropy of the data \(=\ln2=0.693\); so \(D_{\text{KL}}=0.916-0.693=0.223\).

Connections

  • Leads toCost functions of neural nets (L4): networks are trained with exactly this negative log-likelihood.
  • Leads toEmpirical risk minimization (L7): “expectation over \(\hat p_{\text{data}}\)” is the empirical risk.
5.5.1 · Conditional log-likelihood

Conditional likelihood & linear regression as MLE

For supervised learning maximize \(\sum\log p(y^{(i)}\mid\mathbf x^{(i)};\theta)\). If the model predicts a Gaussian around \(\hat y\), this is exactly minimizing the MSE — the justification for the squared error.

\[ \boldsymbol\theta_{\text{ML}}=\arg\max_{\boldsymbol\theta}P(\mathbf Y\mid\mathbf X;\boldsymbol\theta)=\arg\max_{\boldsymbol\theta}\sum_{i=1}^{m}\log P\big(\mathbf y^{(i)}\mid\mathbf x^{(i)};\boldsymbol\theta\big) \](5.62–5.63) \[ p(y\mid\mathbf x)=\mathcal N\big(y;\hat y(\mathbf x;\mathbf w),\sigma^2\big) \](5.64) \[ \sum_{i=1}^{m}\log p\big(y^{(i)}\mid\mathbf x^{(i)};\boldsymbol\theta\big)=-m\log\sigma-\frac m2\log(2\pi)-\sum_{i=1}^{m}\frac{\|\hat y^{(i)}-y^{(i)}\|^2}{2\sigma^2} \](5.65) \[ \text{MSE}_{\text{train}}=\frac1m\sum_{i=1}^{m}\|\hat y^{(i)}-y^{(i)}\|^2 \](5.66)

In plain words

Think of the model as producing a whole distribution of possible y for each x (with infinite data we would see many different y for the same x). Assume it’s a Gaussian centred on the prediction \(\hat y\), with a fixed variance σ² chosen by the user.

In (5.65) only the last term depends on w, and it is \(-\frac{m}{2\sigma^2}\text{MSE}\). So the two criteria have different values but the same optimum.

Terms on this slide

Conditional likelihood
Probability of the targets given the inputs, \(P(\mathbf Y\mid\mathbf X;\theta)\).
\(\mathcal N(y;\hat y,\sigma^2)\)
Gaussian over y with mean \(\hat y\) and variance σ².
Constant terms
\(-m\log\sigma-\frac m2\log2\pi\) don’t depend on w, so they don’t move the optimum.

Calculation, step by step

  1. One point: \(y=3\), prediction \(\hat y=2.5\), σ = 1.
  2. \(\log p=-\log1-\frac12\log(2\pi)-\frac{(2.5-3)^2}{2}=0-0.919-0.125=-1.044\).
  3. If the prediction were 3 exactly: \(-0.919\) (higher). Every unit of squared error costs \(\frac{1}{2\sigma^2}\) log-likelihood.

  • Builds onLinear regression & normal equations (L1).
  • Leads toLinear output units for Gaussian outputs (L4) and sigmoid units for Bernoulli outputs (L4): the same MLE recipe for other output types.
5.4.5 · 5.5.2 · Consistency & properties of ML

Consistency, and why maximum likelihood is preferred

A consistent estimator converges to the truth as data grows. Under mild conditions, maximum likelihood is consistent and efficient — asymptotically no consistent estimator has lower MSE.

\[ \operatorname*{plim}_{m\to\infty}\hat\theta_m=\theta \](5.55)

In plain words

  • Convergence in probability: for any ε > 0, \(P(|\hat\theta_m-\theta|>\varepsilon)\to0\). That is (weak) consistency. Strong consistency: \(P(\lim\hat\theta_m=\theta)=1\) (almost sure convergence).
  • Consistency ⇒ bias disappears with more data. But unbiased does not imply consistent: “use only the first sample” is unbiased forever, yet never converges.
  • ML is consistent if (1) the true \(p_{\text{data}}\) lies inside the model family, and (2) exactly one θ produces it.
  • Efficiency: for large m, the Cramér–Rao lower bound shows no consistent estimator has lower parametric MSE than ML. Consistency + efficiency ⇒ ML is the default choice.

Terms on this slide

plim
Limit in probability.
Consistent
Gets arbitrarily close to the truth with enough data.
Efficient
Reaches a given accuracy with the fewest examples.
Cramér–Rao bound
A theoretical lower limit on the variance of (unbiased) estimators.

Calculation, step by step

  1. Data ~ \(\mathcal N(2,1)\). Sample mean SE \(=1/\sqrt m\): m = 4 → 0.5; m = 100 → 0.1; m = 10 000 → 0.01 → shrinks to 0 → consistent.
  2. Estimator \(\hat\mu=x^{(1)}\): its SE is always \(\sigma=1\) whatever m is → not consistent, though \(\mathbb E[x^{(1)}]=2\) (unbiased).

  • Used byempirical risk and surrogate losses (L7).
5.6 · Bayesian statistics

Bayesian statistics: θ itself is uncertain

Frequentist: θ fixed, data random. Bayesian: data observed (fixed), θ uncertain → a probability distribution over θ that starts as a prior and is updated by the data into a posterior.

\[ p\big(\boldsymbol\theta\mid\mathbf x^{(1)},\dots,\mathbf x^{(m)}\big)=\frac{p\big(\mathbf x^{(1)},\dots,\mathbf x^{(m)}\mid\boldsymbol\theta\big)\,p(\boldsymbol\theta)}{p\big(\mathbf x^{(1)},\dots,\mathbf x^{(m)}\big)} \](5.67) Bayes’ rule \[ p\big(x^{(m+1)}\mid\mathbf x^{(1)},\dots,\mathbf x^{(m)}\big)=\int p\big(x^{(m+1)}\mid\boldsymbol\theta\big)\,p\big(\boldsymbol\theta\mid\mathbf x^{(1)},\dots,\mathbf x^{(m)}\big)\,d\boldsymbol\theta \](5.68) predict with all θ

In plain words

  • Prior \(p(\theta)\): belief before data — usually broad (high entropy), or preferring “simple” solutions (small weights, nearly constant functions).
  • Data usually make the posterior lose entropy and concentrate around a few likely values.
  • Two differences from ML: (1) predictions average over all θ, weighted by the posterior — integrating over uncertainty protects against overfitting; (2) the prior shifts probability toward preferred regions.
  • Pros: much better with little data. Cons: subjective prior; expensive with many examples.

Bayesian linear regression (5.69–5.78)

\[ p(\mathbf y\mid\mathbf X,\mathbf w)=\mathcal N(\mathbf y;\mathbf X\mathbf w,\mathbf I),\qquad p(\mathbf w)=\mathcal N(\mathbf w;\boldsymbol\mu_0,\boldsymbol\Lambda_0) \] \[ \boldsymbol\Lambda_m=\big(\mathbf X^{\top}\mathbf X+\boldsymbol\Lambda_0^{-1}\big)^{-1},\qquad\boldsymbol\mu_m=\boldsymbol\Lambda_m\big(\mathbf X^{\top}\mathbf y+\boldsymbol\Lambda_0^{-1}\boldsymbol\mu_0\big) \]

The posterior is Gaussian \(\mathcal N(\mathbf w;\boldsymbol\mu_m,\boldsymbol\Lambda_m)\). With \(\boldsymbol\mu_0=0\), \(\boldsymbol\Lambda_0=\frac1\alpha\mathbf I\): \(\boldsymbol\mu_m=(\mathbf X^\top\mathbf X+\alpha\mathbf I)^{-1}\mathbf X^\top\mathbf y\) — the same as weight decay αwᵀw. Extra: \(\boldsymbol\Lambda_m\) tells how uncertain each weight is. (α = 0 is not allowed: an infinitely wide prior.)

Terms on this slide

Prior \(p(\theta)\)
Belief about θ before seeing data.
Likelihood \(p(\text{data}\mid\theta)\)
How well each θ explains the data.
Posterior \(p(\theta\mid\text{data})\)
Updated belief after seeing the data.
Evidence \(p(\text{data})\)
Normalizing constant so the posterior integrates to 1.
Entropy
How spread out (uncertain) a distribution is.
Beta(a, b)
A distribution on [0, 1]; works like a + b imaginary prior flips (a heads, b tails).
\(\boldsymbol\Lambda\)
Covariance matrix: spread and correlations of the weights.

Calculation, step by step

  1. Prior Beta(2, 2) (mild belief in a fair coin). Observe 7 heads, 3 tails.
  2. Posterior ∝ \(\theta^{7}(1-\theta)^{3}\cdot\theta^{1}(1-\theta)^{1}=\theta^{8}(1-\theta)^{4}\) = Beta(9, 5).
  3. Posterior mean (prediction for next flip) \(=9/(9+5)=0.643\); MAP \(=(9-1)/(9+5-2)=8/12=0.667\); MLE \(=0.7\). The prior pulls the answer toward 0.5.

5.6.1 · MAP estimation

MAP: one best guess that still uses the prior

MAP picks the peak of the posterior: maximize log-likelihood + log-prior. A Gaussian prior on the weights turns the log-prior into a weight-decay penalty — less variance, more bias.

\[ \boldsymbol\theta_{\text{MAP}}=\arg\max_{\boldsymbol\theta}p(\boldsymbol\theta\mid\mathbf x)=\arg\max_{\boldsymbol\theta}\ \log p(\mathbf x\mid\boldsymbol\theta)+\log p(\boldsymbol\theta) \](5.79) \[ p(\mathbf w)=\mathcal N\big(\mathbf w;\mathbf 0,\tfrac1\lambda\mathbf I\big)\;\Rightarrow\;\log p(\mathbf w)=-\frac\lambda2\mathbf w^{\top}\mathbf w+\text{const} \]

In plain words

  • The full posterior is often intractable; a point estimate is a tractable approximation.
  • MAP keeps some Bayesian benefit: the prior adds information not in the data, which reduces variance at the price of increased bias.
  • Not every regularizer is a MAP prior (some are not log-probabilities; some depend on the data, which a prior can’t).
  • MAP gives a recipe for designing penalties: e.g. a mixture of Gaussians prior gives a more complex, interpretable penalty.

Terms on this slide

MAP
Maximum a posteriori: the most probable θ after seeing the data.
Log-prior
\(\log p(\theta)\); acts as a penalty added to the log-likelihood.
Precision α (or λ)
1 / variance of the prior: bigger = stronger belief that weights are near 0.

Calculation, step by step

  1. 1-D model \(y=wx+\epsilon\), noise variance 1, prior \(w\sim\mathcal N(0,1/\alpha)\).
  2. −log posterior \(=\frac12\sum(y-wx)^2+\frac\alpha2w^2+\text{const}\). Derivative \(=-\sum xy+w\sum x^2+\alpha w=0\).
  3. So \(w_{\text{MAP}}=\frac{\sum xy}{\sum x^2+\alpha}\) vs. \(w_{\text{ML}}=\frac{\sum xy}{\sum x^2}\).
  4. With \(\sum xy=3,\sum x^2=2,\alpha=1\): \(w_{\text{ML}}=1.5\), \(w_{\text{MAP}}=3/3=1.0\) — shrunk toward 0.

Connections

  • Builds onWeight decay (L1).
  • Leads toL2 regularization (L6) (Gaussian prior) and L1 regularization (L6) (Laplace prior → sparse weights).
5.11.1 · Challenges motivating deep learning

The curse of dimensionality

The number of distinct configurations grows exponentially with the number of input dimensions, so in high dimensions almost every region of input space has no training example.

In plain words

Simple ML algorithms work on many problems but failed on the central AI tasks (speech, object recognition) — partly because they don’t generalize in high dimensions.

Imagine cutting input space into grid cells. In low dimensions, each cell has examples: to estimate a density, count examples in the cell; to classify, take the majority class in the cell; to regress, average the targets in the cell. In high dimensions, a typical cell is empty — what then? Classic methods assume the answer is about the same as at the nearest training point.

This is a statistical challenge: there are far more possible configurations than training examples.

Terms on this slide

Dimension d
Number of input features (pixels, words…).
Configuration
One combination of values of all features (one grid cell).
Statistical challenge
Too few examples compared with the number of possible inputs.

Calculation, step by step

  1. 10 bins per axis: d = 1 → 10 cells; d = 2 → 100; d = 3 → 1 000; d = 10 → \(10^{10}\).
  2. With m = 500 examples in d = 3: chance a given cell is empty \(=(1-\frac1{1000})^{500}\approx e^{-0.5}=0.61\) → only ~39% of cells have any data.
  3. A tiny 28×28 grey image already has 784 dimensions — far beyond any grid.

Connections

  • Leads toParameter sharing in CNNs (L10): one way deep learning beats the curse — the same small detector is reused everywhere.
5.11.2 · Local constancy and smoothness

The smoothness prior is not enough — enter deep learning

“The function doesn’t change much in a small region” only lets you distinguish about as many regions as you have examples. Deep learning assumes data come from a composition of factors, giving an exponential gain.

In plain words

  • To generalize, an algorithm needs prior beliefs. The most common implicit one is the smoothness (local constancy) prior: the learned function shouldn’t change much within a small region.
  • Many simple algorithms (nearest neighbour, kernel machines, decision trees) rely only on it, so they need at least one example per region — they fail to scale to AI-level tasks.
  • Core idea of deep learning: the data were generated by a composition of factors / features, possibly at multiple levels of a hierarchy. This mild assumption gives an exponential relationship between the number of examples and the number of regions that can be distinguished — countering the exponential curse.

Terms on this slide

Smoothness / local constancy prior
Nearby inputs should get similar outputs.
Nearest neighbour
Predict the label of the closest training example.
Distributed representation
Describe an input by many features at once (e.g. “has glasses”, “is smiling”…), so combinations cover many regions.

Calculation, step by step

  1. Checkerboard with 8×8 = 64 regions: a local method needs examples in all 64 regions (in practice many more).
  2. With 20 learned binary features, combinations can distinguish \(2^{20}\approx1\,000\,000\) regions while learning only 20 features from data.
  3. That exponential gap (64 examples per 64 regions vs. ~20 features for a million regions) is the promise of deep, distributed representations.

Connections

  • Builds onNo free lunch (L1): we must choose assumptions that match the real world.
  • Leads toDepth & universal approximation (L4): deep networks can represent such compositions with far fewer units.
5.7.1 · Probabilistic supervised learning

From linear regression to logistic regression

For two classes, predict a probability: squash \(\boldsymbol\theta^\top\mathbf x\) into (0, 1) with the sigmoid. There is no closed-form solution, so we minimize the negative log-likelihood with gradient descent.

\[ p(y\mid\mathbf x;\boldsymbol\theta)=\mathcal N\big(y;\boldsymbol\theta^{\top}\mathbf x,\mathbf I\big)\quad\text{(linear regression)} \](5.80) \[ p(y=1\mid\mathbf x;\boldsymbol\theta)=\sigma\big(\boldsymbol\theta^{\top}\mathbf x\big),\qquad\sigma(z)=\frac{1}{1+e^{-z}} \](5.81) logistic regression \[ \text{NLL}=-\frac1m\sum_i\Big[y^{(i)}\log\sigma(z^{(i)})+(1-y^{(i)})\log\big(1-\sigma(z^{(i)})\big)\Big],\quad\frac{\partial\,\text{NLL}}{\partial\boldsymbol\theta}=\frac1m\sum_i\big(\sigma(z^{(i)})-y^{(i)}\big)\mathbf x^{(i)} \]

In plain words

  • Most supervised learning = estimating \(p(y\mid\mathbf x)\) by maximum likelihood for some parametric family.
  • With 2 classes we only need \(p(y=1\mid\mathbf x)\) (the other is 1 minus it). A probability must be in (0, 1), so wrap the linear function in the sigmoid.
  • Strange name: “regression”, but used for classification.
  • The same strategy works for essentially any supervised problem: write a family of conditional distributions for your output type, then minimize the NLL.

Terms on this slide

Sigmoid σ(z)
S-shaped squashing function; σ(0) = 0.5, σ(large) → 1, σ(very negative) → 0.
Logit z
The linear score \(\boldsymbol\theta^\top\mathbf x\) before squashing.
NLL
Negative log-likelihood: the loss we minimize (binary cross-entropy).
Closed form
A direct formula for the answer (like the normal equations) — logistic regression has none.

Calculation, step by step

  1. w = 1.5, b = −1, input x = 2: \(z=1.5\cdot2-1=2\).
  2. \(\sigma(2)=1/(1+e^{-2})=1/(1+0.135)=0.881\).
  3. If y = 1: loss \(=-\ln0.881=0.127\) (confident & right = small). If y = 0: loss \(=-\ln(1-0.881)=-\ln0.119=2.13\) (confident & wrong = big).
  4. Gradient for this example if y = 1: \((\sigma(z)-y)x=(0.881-1)\cdot2=-0.238\) → gradient descent increases w a little.

Generative vs. discriminative models

Three ways to build a classifier

Generative: model how each class produces inputs, then use Bayes. Discriminative: model the class probabilities given the input directly. Discriminant function: map input straight to a label.

\[ p(\mathcal C_k\mid\mathbf x)=\frac{p(\mathbf x\mid\mathcal C_k)\,p(\mathcal C_k)}{p(\mathbf x)},\qquad p(\mathbf x)=\sum_k p(\mathbf x\mid\mathcal C_k)\,p(\mathcal C_k) \]
(a) GenerativeLearn \(p(\mathbf x\mid\mathcal C_k)\) and \(p(\mathcal C_k)\) (or the joint \(p(\mathbf x,\mathcal C_k)\)). Can sample new x, and gives \(p(\mathbf x)\) for outlier / novelty detection. Most demanding: high-dimensional x needs lots of data.
(b) DiscriminativeLearn \(p(\mathcal C_k\mid\mathbf x)\) directly (e.g. logistic regression). Uses data and compute only for what decisions need.
(c) Discriminant functionLearn \(f(\mathbf x)\) that outputs the label directly (e.g. f = 0 → class 1, f = 1 → class 2). No probabilities at all.

Terms on this slide

Class-conditional density \(p(\mathbf x\mid\mathcal C_k)\)
How inputs of class k are distributed.
Class prior \(p(\mathcal C_k)\)
How common class k is before looking at x.
Posterior \(p(\mathcal C_k\mid\mathbf x)\)
Probability of class k for this particular input.
Decision theory
Rules for turning probabilities into decisions (e.g. pick the most probable class).
Novelty detection
Flagging inputs with low \(p(\mathbf x)\), where predictions may be unreliable.

Calculation, step by step

  1. Priors \(p(\mathcal C_1)=p(\mathcal C_2)=0.5\); at some x: \(p(\mathbf x\mid\mathcal C_1)=0.1\), \(p(\mathbf x\mid\mathcal C_2)=0.3\).
  2. \(p(\mathbf x)=0.5\cdot0.1+0.5\cdot0.3=0.05+0.15=0.2\).
  3. \(p(\mathcal C_2\mid\mathbf x)=0.15/0.2=0.75\), \(p(\mathcal C_1\mid\mathbf x)=0.25\) → decide class 2.

Wrap-up

Summary: how it all connects

Estimators are random → judge them by bias and variance. Maximum likelihood gives the loss; a prior (MAP) gives the regularizer. High dimensions break local methods, which motivates deep models.
