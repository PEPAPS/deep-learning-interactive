Where this lecture fits in training

This lecture defines the first and last steps of every training run: what problem we solve and with which data (step 1), and how we check that the model works on new data (step 8). Linear regression gives a first complete example of the loop.

Step 1 · the problem

Every project starts by fixing the task, the performance measure and the data. The data is split into training, validation and test parts.

Steps 2–7 · fitting

Choose a model family (its capacity), a loss (here mean squared error, maybe plus weight decay) and minimize it. For linear regression the minimum is found in one formula.

Step 8 · generalization

What we really care about is the test error. Validation data and cross-validation tell us which capacity / hyper-parameters generalize best.

5.1 · Learning algorithms

What does it mean to “learn”?

A program learns if it gets better at a task (as measured by some score) the more data / experience it gets.

In plain words

A machine learning algorithm is an algorithm that is able to learn from data. Tom Mitchell (1997) gave the classic definition:

“A computer program is said to learn from experience E with respect to some class of tasks T and performance measure P, if its performance at tasks in T, as measured by P, improves with experience E.”

Note: learning is not the task. If we want a robot to walk, walking is the task; learning is just how the robot gets the ability to walk.

Terms on this slide

Task T
What the system should do with an example, e.g. “decide whether this e-mail is spam”.
Example
One object or event described by measured numbers called features, written as a vector \(\mathbf x\in\mathbb R^n\) (e.g. the pixel values of one image).
Feature \(x_i\)
One measured number of the example, e.g. the brightness of pixel i, or the petal length of a flower.
Performance measure P
A number that tells how well the task is done, e.g. accuracy.
Experience E
What the algorithm is allowed to see while learning — usually a dataset of examples.

Analogy

A student learning to cook: T = cook pasta, P = how tasty the guests rate it (1–10), E = the number of times they practised. If the ratings go up with practice, the student is learning.

Connections to other lectures

  • Leads toFeedforward networks (L4): a neural network is just a very flexible way to represent the function that performs task T.
  • Leads toSurrogate losses (L7): the performance measure P (e.g. accuracy) is often impossible to optimize directly, so we train on a different, smooth loss.
5.1.1 · The task, T

The zoo of machine learning tasks

Tasks are described by what goes in and what must come out. The output type (a class, a number, a sequence, a probability…) decides which model and which loss we will use later.

In plain words

The lecture lists eleven classic tasks. Most real applications are one of them, or a mix:

  • Classification — handwriting, faces, objects, spam, music genre, recommendation.
  • Regression — prices, insurance claims, weather.
  • Transcription & translation — speech → text, photo of text → text, English → French.
  • Structured output — parsing, segmentation of every pixel, image captioning.
  • Anomaly detection, synthesis, imputation, denoising, density estimation.

Density estimation is special: if you know \(p(\mathbf x)\) you can, in principle, solve the others, e.g. fill in a missing value with \(p(x_i\mid\mathbf x_{-i})\). In practice those computations are often intractable (too expensive to compute).

Terms on this slide

\(f:\mathbb R^n\to\{1,\dots,k\}\)
A classifier: a function that takes n input numbers and returns one of k category codes.
\(f:\mathbb R^n\to\mathbb R\)
A regressor: returns one real number.
Structured output
The output has several parts that must fit together (the words of a caption must form a sentence).
Marginalizing
Summing (or integrating) a probability over the variables you don’t know, to get the probability of the ones you care about.
\(p(x_i\mid\mathbf x_{-i})\)
Probability of feature i given all the other features (\(-i\) means “all except i”).
Intractable
Possible in theory, but far too expensive to compute in practice.

Connections to other lectures

  • Leads toOutput units (L4): the task decides the last layer — linear for regression, sigmoid for yes/no, softmax for k classes.
  • Leads toConvolutional nets (L10) for images and recurrent nets (L11) for sequences (transcription, translation, captioning).
5.1.2 · The performance measure, P

Measuring success

P must be measured on a test set of data the model never saw, and choosing P is a real design decision — different measures can prefer different models.

In plain words

  • Classification / transcription: accuracy = fraction of correct outputs, or equivalently the error rate = fraction of wrong outputs (also called the expected 0-1 loss).
  • Density estimation: accuracy makes no sense; use the average log-probability the model gives to test examples (higher = better).
  • Always evaluate on a separate test set: we care about performance in the real world, on new data.

Hard questions: should a transcription system get partial credit for a half-correct sentence? In regression, is it worse to make many medium mistakes or a few huge ones? Sometimes the ideal measure is also impractical to compute, so we use an approximation.

Terms on this slide

Accuracy
\(\frac{\#\text{correct}}{\#\text{examples}}\).
Error rate
\(1-\text{accuracy}\) = \(\frac{\#\text{wrong}}{\#\text{examples}}\).
0-1 loss
Loss of 0 for a correct answer and 1 for a wrong one; its average is the error rate.
Log-probability
\(\log p_{\text{model}}(\mathbf x)\): how much probability the model gave to what actually happened. Higher (closer to 0) is better.
Test set
Examples kept aside and never used for training or for choosing the model.
MAE / MSE
Mean absolute error \(\frac1m\sum|e_i|\) and mean squared error \(\frac1m\sum e_i^2\) for regression.

Calculation, step by step

  1. A spam filter is tested on 200 new e-mails and gets 184 right.
  2. Accuracy \(=184/200=0.92\) (92%). Error rate \(=1-0.92=0.08\) (16 wrong out of 200).
  3. A density model gives three test points probabilities 0.5, 0.25 and 0.125. Average log-probability (natural log): \(\frac{\ln 0.5+\ln 0.25+\ln 0.125}{3}=\frac{-0.693-1.386-2.079}{3}=-1.386\). A better model would get a number closer to 0.

Connections to other lectures

  • Leads toMaximum likelihood (L2): maximizing the average log-probability is exactly how most models are trained.
  • Leads toSurrogate losses (L7): the 0-1 loss has zero gradient almost everywhere, so networks are trained with a smooth substitute such as cross-entropy.
5.1.3 · The experience, E

Experience: supervised, unsupervised and more

Supervised learning learns \(p(y\mid\mathbf x)\) from examples with labels; unsupervised learning learns about \(p(\mathbf x)\) from examples without labels. The dataset is usually stored as a design matrix.

In plain words

  • Unsupervised: see many examples of \(\mathbf x\); learn the distribution \(p(\mathbf x)\) or useful structure (e.g. clustering).
  • Supervised: see pairs \((\mathbf x, y)\) — a “teacher” provides the label \(y\); learn to predict \(y\) from \(\mathbf x\), usually by estimating \(p(y\mid\mathbf x)\).
  • Semi-supervised: only some examples have labels. Multi-instance: a whole bag of examples is labelled (“contains a cat”), not the individual members.
  • Reinforcement learning: no fixed dataset — the agent acts, the environment responds, so there is a feedback loop.

The line between supervised and unsupervised is blurry. The two formulas below convert one into the other.

\[ p(\mathbf x)=\prod_{i=1}^{n}p(x_i\mid x_1,\dots,x_{i-1}) \](5.1) unsupervised → n supervised problems \[ p(y\mid\mathbf x)=\frac{p(\mathbf x,y)}{\sum_{y'}p(\mathbf x,y')} \](5.2) supervised from a joint (unsupervised) model

Terms on this slide

Dataset
A collection of examples (also called data points).
Label / target \(y\)
The correct answer attached to an example (e.g. the iris species).
Design matrix \(\mathbf X\in\mathbb R^{m\times n}\)
Table with one example per row (m rows) and one feature per column (n columns). Iris: \(m=150,n=4\); \(X_{i,1}\) is the sepal length of plant i.
Label vector \(\mathbf y\)
\(y_i\) is the label of example i.
Set notation \(\{\mathbf x^{(1)},\dots,\mathbf x^{(m)}\}\)
Used when examples have different sizes (photos of different widths) and can’t be rows of one matrix.
Chain rule of probability
A joint probability equals a product of conditional probabilities, one variable at a time (formula 5.1).

Calculation, step by step

  1. Formula 5.2 with numbers: suppose a joint model gives for one flower \(\mathbf x\): \(p(\mathbf x,\text{setosa})=0.02\), \(p(\mathbf x,\text{versicolor})=0.06\), \(p(\mathbf x,\text{virginica})=0.12\).
  2. Denominator: \(0.02+0.06+0.12=0.20\).
  3. So \(p(\text{virginica}\mid\mathbf x)=0.12/0.20=0.6\), \(p(\text{versicolor}\mid\mathbf x)=0.3\), \(p(\text{setosa}\mid\mathbf x)=0.1\) — a supervised prediction obtained from an unsupervised (joint) model.

Connections to other lectures

  • Leads toProbabilistic supervised learning (L2) and generative vs. discriminative models (L2): modelling \(p(y\mid\mathbf x)\) directly vs. modelling \(p(\mathbf x,y)\).
  • Leads toMinibatches (L7): during training we read random groups of rows of the design matrix.
5.1.4 · Example

Our first learning algorithm: linear regression

Predict with a weighted sum \(\hat y=\mathbf w^\top\mathbf x+b\), measure the mean squared error, and find the weights that make it smallest by setting its gradient to zero — the normal equations.

In plain words

  • T: predict a number \(y\) from \(\mathbf x\). Model: \(\hat y=\mathbf w^\top\mathbf x\). Each weight \(w_i\) says how much feature \(x_i\) pushes the prediction up (positive) or down (negative); weight 0 = feature ignored.
  • P: mean squared error on a test set.
  • E / learning: choose \(\mathbf w\) to minimize the MSE on the training set.
\[ \hat y=\mathbf w^{\top}\mathbf x \](5.3) \[ \text{MSE}_{\text{test}}=\frac1m\sum_i\big(\hat{\mathbf y}^{(\text{test})}-\mathbf y^{(\text{test})}\big)_i^2=\frac1m\big\|\hat{\mathbf y}^{(\text{test})}-\mathbf y^{(\text{test})}\big\|_2^2 \](5.4–5.5) \[ \nabla_{\mathbf w}\tfrac1m\|\mathbf X\mathbf w-\mathbf y\|_2^2=0\;\Rightarrow\;2\mathbf X^{\top}\mathbf X\mathbf w-2\mathbf X^{\top}\mathbf y=0\;\Rightarrow\;\mathbf w=(\mathbf X^{\top}\mathbf X)^{-1}\mathbf X^{\top}\mathbf y \](5.6–5.12) normal equations

The bias (intercept) b

With \(\hat y=\mathbf w^\top\mathbf x+b\) the line need not pass through the origin (an affine function). Trick: add a feature that is always 1 — its weight plays the role of b. Careful: this “bias parameter” is not the statistical bias of an estimator (next lecture).

Terms on this slide

\(\hat y\)
“y-hat”: the model’s prediction (y is the true value).
\(\mathbf w^\top\mathbf x\)
Dot product \(w_1x_1+\dots+w_nx_n\).
\(\|\mathbf v\|_2^2\)
Squared Euclidean length \(v_1^2+\dots+v_m^2\). So the MSE grows with the distance between predictions and targets.
Gradient \(\nabla_{\mathbf w}\)
Vector of slopes of the error w.r.t. each weight; at the minimum of a bowl it is zero.
Normal equations
The linear system \(\mathbf X^\top\mathbf X\mathbf w=\mathbf X^\top\mathbf y\); solving it is the learning algorithm.
Affine
Linear plus a constant (\(\mathbf w^\top\mathbf x+b\)). The course often just says “linear”.

Calculation, step by step (3 points)

  1. Data: \(x=(1,2,3)\), \(y=(2,3,5)\). Add the column of 1s: \(\mathbf X=\begin{bmatrix}1&1\\1&2\\1&3\end{bmatrix}\), unknowns \((b,w)\).
  2. \(\mathbf X^\top\mathbf X=\begin{bmatrix}3&6\\6&14\end{bmatrix}\) (3 points, \(\sum x=6\), \(\sum x^2=14\)); \(\mathbf X^\top\mathbf y=\begin{bmatrix}10\\23\end{bmatrix}\) (\(\sum y=10\), \(\sum xy=2+6+15=23\)).
  3. Inverse of a 2×2: determinant \(3\cdot14-6\cdot6=6\), so \((\mathbf X^\top\mathbf X)^{-1}=\frac16\begin{bmatrix}14&-6\\-6&3\end{bmatrix}\).
  4. \(b=\frac{14\cdot10-6\cdot23}{6}=\frac{2}{6}=0.333\), \(\;w=\frac{-6\cdot10+3\cdot23}{6}=\frac{9}{6}=1.5\).
  5. Predictions 1.833, 3.333, 4.833 → errors −0.167, 0.333, −0.167 → MSE \(=\frac{0.0278+0.1111+0.0278}{3}=0.056\). No other line has a smaller MSE.

Connections to other lectures

  • Leads toLinear regression as maximum likelihood (L2): minimizing MSE = maximizing likelihood under Gaussian noise.
  • Leads toLeast squares by gradient descent (L3): when \(\mathbf X^\top\mathbf X\) is too big to invert, we walk downhill instead.
  • Leads toLinear output units (L4): the last layer of a regression network is exactly this model.
5.2 · Capacity, overfitting and underfitting

Generalization: the central challenge

Optimization only asks for a small training error. Machine learning also wants a small test error. Two goals: (1) make the training error small, and (2) make the gap between training and test error small.

In plain words

Generalization = performing well on new, previously unseen inputs. We train by lowering the training error, but we are judged by the generalization (test) error: the expected error on a new input.

How can the training set tell us anything about the test set? Only if we assume they come from the same process: the i.i.d. assumptions — examples are independent of each other, and training and test examples are identically distributed, drawn from the same data-generating distribution \(p_{\text{data}}\).

For a model fixed in advance, expected training error = expected test error. But we choose the parameters using the training set, so the expected test error is ≥ the expected training error.

\[ \text{train:}\ \frac{1}{m^{(\text{train})}}\big\|\mathbf X^{(\text{train})}\mathbf w-\mathbf y^{(\text{train})}\big\|_2^2 \qquad \text{test:}\ \frac{1}{m^{(\text{test})}}\big\|\mathbf X^{(\text{test})}\mathbf w-\mathbf y^{(\text{test})}\big\|_2^2 \](5.14–5.15) we minimize the first, but care about the second

Terms on this slide

Training error
Error measured on the examples used to fit the model.
Generalization / test error
Expected error on a new input; estimated on a separate test set.
Data-generating process
The (unknown) random process that produces the data.
i.i.d.
Independent and identically distributed: each example is drawn separately, all from the same distribution \(p_{\text{data}}\).
Underfitting
Goal 1 fails: training error is too large.
Overfitting
Goal 2 fails: the gap between training and test error is too large.

Calculation, step by step

  1. Model A: training MSE 0.30, test MSE 0.33 → gap 0.03, but the training error is high → underfitting.
  2. Model B: training MSE 0.01, test MSE 0.45 → gap 0.44 → overfitting.
  3. Model C: training MSE 0.06, test MSE 0.08 → both small → good generalization. Pick C.

Connections to other lectures

  • Leads toEmpirical risk minimization (L7): training = minimizing the average loss on the training set as a stand-in for the true expected loss.
  • Leads toRegularization (L6): the whole chapter is about shrinking the gap (goal 2).
5.2 · Capacity

Capacity: how flexible is the model family?

Too little capacity → underfitting (can’t fit even the training data). Too much capacity for the amount of data → overfitting (memorizes noise). The best capacity matches the complexity of the task and the amount of data.

In plain words

A model’s capacity is its ability to fit a wide variety of functions. One way to control it is to choose the hypothesis space — the set of functions the algorithm is allowed to pick from.

Linear regression can only draw straight lines. Add \(x^2\) as an extra feature and it can draw parabolas; add up to \(x^9\) and it can draw very wiggly curves. The model is still linear in the parameters, so the normal equations still solve it in closed form.

\[ \hat y=b+wx\qquad\hat y=b+w_1x+w_2x^2\qquad\hat y=b+\sum_{i=1}^{9}w_ix^i \](5.15–5.17) degree 1, 2 and 9

Terms on this slide

Capacity
How many / how complex the functions a model can represent.
Hypothesis space
The set of all functions the learning algorithm may choose as its answer.
Representational capacity
The family of functions the model could express by varying its parameters.
Effective capacity
What the learning algorithm actually reaches — limited by the optimizer, so it can be smaller.
Occam’s razor
Among explanations that fit the data equally well, prefer the simplest.

Calculation, step by step

  1. Degree-3 model, input \(x=0.5\). Features: \((1,\;x,\;x^2,\;x^3)=(1,\;0.5,\;0.25,\;0.125)\).
  2. Weights \((b,w_1,w_2,w_3)=(0.1,\;2,\;-1,\;0.5)\).
  3. \(\hat y=0.1+2(0.5)-1(0.25)+0.5(0.125)=0.1+1-0.25+0.0625=0.9125\). Same dot-product as linear regression — just with more features.
  4. Parameters: degree d has d + 1 weights. With m = 10 points, degree 9 has 10 weights → it can pass through every point exactly (zero training error) — usually overfitting.

Connections to other lectures

  • Leads toBias–variance trade-off (L2): underfitting ≈ high bias, overfitting ≈ high variance.
  • Leads toUniversal approximation (L4): neural networks have enormous capacity; the question becomes how to control it.
5.2 · Capacity (continued)

The U-shaped curve, VC dimension and Bayes error

As capacity grows, training error keeps falling but test error falls and then rises: a U-shape. More training data shrinks the gap. No model can beat the Bayes error caused by noise.

In plain words

  • Statistical learning theory proves: the gap between training and test error is bounded by a quantity that grows with capacity and shrinks with more training examples.
  • The VC dimension measures the capacity of a binary classifier: the largest number of points it can label in every possible way (“shatter”).
  • These bounds are loose and hard to compute for deep networks (their effective capacity depends on the optimizer), so in practice we measure instead.
  • Bayes error: the error of an oracle that knows the true distribution \(p(\mathbf x,y)\). It is > 0 when \(y\) is noisy, or depends on variables not in \(\mathbf x\).
  • More data never increases the expected generalization error. Even with optimal capacity there can be a big gap — then gather more data.

Terms on this slide

Optimal capacity
The capacity at the bottom of the test-error U-curve.
Shatter
A classifier shatters m points if, for every one of the \(2^m\) ways to label them, some setting of the classifier gets all labels right.
VC dimension
The largest m that the classifier can shatter.
Bayes error
Lowest possible error, reached by knowing the true distribution; caused by noise.
Non-parametric model
A model whose size grows with the data (e.g. nearest neighbour: “copy the label of the closest training point”).

Calculation, step by step

  1. A straight-line classifier in 2-D. Three points not on one line: all \(2^3=8\) labelings can be separated by some line → shattered.
  2. Four points: the “XOR” labeling (diagonal corners share a label) can’t be separated by any line → not shattered.
  3. So the VC dimension of a line in 2-D is 3. More generally, a linear classifier in n dimensions has VC dimension n + 1.
  4. In the demo, noise std σ = 0.25 → the Bayes error is \(\sigma^2=0.25^2=0.0625\): even the true sine curve has this MSE.

Connections to other lectures

  • Leads toLearning XOR (L4): the 4-point labeling a line can’t shatter is exactly the problem that motivates hidden layers.
  • Leads toEarly stopping (L6): watching the validation curve go up during training is the same U-shape, over training time.
5.2.1 · No free lunch

No free lunch: there is no universally best algorithm

Averaged over all possible worlds, every classifier is equally good on unseen points. Algorithms win only by making assumptions that match the real world.

In plain words

Averaged over all possible data-generating distributions, every classification algorithm has the same error rate on previously unobserved points. The most sophisticated algorithm is, on average over all tasks, no better than always predicting the same class.

Luckily, we don’t live in “all possible worlds”. If we make assumptions about the kinds of distributions found in real-world applications, we can design algorithms that do well on those. The goal of ML research is therefore to understand which distributions matter in the real world, and which algorithms work well on them.

Terms on this slide

Data-generating distribution
The true (unknown) rule that produces examples and labels.
Averaged over all distributions
Every possible way of labelling the unseen points counted as equally likely.
Prior assumption
A belief about the world built into the algorithm, e.g. “nearby inputs have similar outputs”.

Calculation, step by step

  1. 3 unseen points → \(2^3=8\) possible true labelings (“worlds”).
  2. Your algorithm predicts (1, 1, 1). In the world (0, 0, 0) it gets 0/3 right; in (1, 1, 1) 3/3; in the three worlds with one 1 it gets 1/3; in the three with two 1s, 2/3.
  3. Average over the 8 worlds: \(\frac{0+3\cdot\frac13+3\cdot\frac23+1}{8}=\frac{0+1+2+1}{8}=0.5\). Any prediction gives the same 50% — try it in the demo.

Connections to other lectures

  • Leads toSmoothness prior & why deep learning (L2): which assumptions deep learning makes about the real world.
  • Leads toConvolution as an infinitely strong prior (L10): a concrete, very successful real-world assumption for images.
5.2.2 · Regularization

Regularization: expressing preferences

Instead of removing functions from the hypothesis space, add a preference: e.g. prefer small weights. The preferred solution wins unless the other one fits the data much better.

In plain words

Weight decay adds the size of the weights to the training criterion. \(\lambda\) is chosen in advance: \(\lambda=0\) means no preference; larger \(\lambda\) forces smaller weights. The result trades off fitting the data against being small — smaller slopes, or weight on fewer features.

In general, add a penalty called a regularizer \(\Omega(\mathbf w)\) to the cost; weight decay uses \(\Omega(\mathbf w)=\mathbf w^\top\mathbf w\). Excluding a function from the hypothesis space is like an infinitely strong preference against it.

Definition: regularization is any modification to a learning algorithm intended to reduce its generalization error but not its training error. By no free lunch, there is no best regularizer — but deep learning finds that a few general-purpose ones work on a wide range of tasks.

\[ J(\mathbf w)=\text{MSE}_{\text{train}}+\lambda\,\mathbf w^{\top}\mathbf w \](5.18)

Terms on this slide

\(J(\mathbf w)\)
The training criterion (cost) that the algorithm minimizes.
\(\lambda\) (lambda)
Regularization strength — a hyper-parameter chosen before training.
\(\mathbf w^\top\mathbf w\)
Sum of squared weights \(w_1^2+\dots+w_n^2\) (squared \(L^2\) norm).
Regularizer \(\Omega\)
Any penalty term added to the cost to express a preference.
Weight decay
The \(\lambda\mathbf w^\top\mathbf w\) penalty; during gradient descent it shrinks (“decays”) the weights a little every step.

Calculation, step by step

  1. \(\lambda=0.01\). Candidate A: MSE 0.040 with weights (3, −4): \(\mathbf w^\top\mathbf w=9+16=25\) → \(J=0.040+0.01\times25=0.290\).
  2. Candidate B: MSE 0.060 with weights (1, −1): \(\mathbf w^\top\mathbf w=2\) → \(J=0.060+0.01\times2=0.080\).
  3. B fits slightly worse but has a much smaller \(J\) → weight decay picks B. With \(\lambda=0\) it would pick A.

Connections to other lectures

  • Leads toL2 regularization in depth (L6): how weight decay shrinks weights along each eigen-direction.
  • Leads toMAP estimation (L2): weight decay is exactly a Gaussian prior on the weights.
5.3 · Hyper-parameters and validation sets

Hyper-parameters and the validation set

Settings that control capacity can’t be learned on the training set — it always picks the maximum capacity. Use a separate validation set carved from the training data; never touch the test set.

In plain words

Hyper-parameters are settings of the algorithm that the learning algorithm itself does not adapt: e.g. the polynomial degree, or \(\lambda\) of weight decay. Sometimes because they are hard to optimize, but mostly because learning them on the training set would always choose maximum capacity → overfitting.

  1. Split the data: test set aside (never used for any choice).
  2. Split the rest: ~80% training, ~20% validation.
  3. Train with each hyper-parameter value on the training part; compare on the validation part.
  4. Pick the best, (optionally retrain), then report the test error once.

Terms on this slide

Parameter
Learned by the training algorithm (weights \(\mathbf w\), bias b).
Hyper-parameter
Chosen outside training (degree, \(\lambda\), learning rate, number of layers…).
Validation set
Training examples held out to estimate generalization error while choosing hyper-parameters.
Test set
Used only once, at the end, for an unbiased final score.

Calculation, step by step

  1. You have 1 250 labelled examples. Put 250 aside as the test set.
  2. The remaining 1 000 → \(0.8\times1000=800\) training, \(200\) validation.
  3. Validation MSE for degrees 1, 3, 9: 0.21, 0.07, 0.95 → choose degree 3. Training MSE would have chosen degree 9.

Connections to other lectures

  • Leads toEarly stopping (L6): the number of training steps is a hyper-parameter chosen with the validation curve.
  • Leads toChoosing an optimizer and learning rate (L8): also hyper-parameters tuned on validation data.
5.3.1 · Cross-validation

k-fold cross-validation

When data is scarce, a single small test set gives a noisy estimate. Rotate: split into k folds, test on each fold once, train on the rest, and average the k errors.

In plain words

A fixed split can leave a very small test set, so the error estimate is unreliable. Instead, repeat training and testing on different splits of the same data. In k-fold cross-validation the dataset is split into k non-overlapping subsets (folds). On trial i, fold i is the test set and the other k − 1 folds are the training set. The estimate is the average test error over the k trials.

Cost: you train k times. Benefit: every example is used for testing exactly once, and for training k − 1 times.

\[ \widehat{\text{err}}_{\text{CV}}=\frac1k\sum_{i=1}^{k}\text{err}\big(\text{model trained without fold }i,\ \text{fold }i\big) \]

Terms on this slide

Fold
One of the k equal, non-overlapping parts of the dataset.
Trial
One round: train on k − 1 folds, test on the remaining fold.
Leave-one-out
The extreme case k = m: every fold is a single example.

Calculation, step by step

  1. 100 examples, k = 5 → five folds of 20 examples.
  2. Trial errors: 0.12, 0.10, 0.15, 0.09, 0.14.
  3. CV estimate \(=\frac{0.12+0.10+0.15+0.09+0.14}{5}=\frac{0.60}{5}=0.12\). The spread (0.09–0.15) shows how uncertain a single small split would have been.

Connections to other lectures

  • Leads toVariance and standard error (L2): how to put error bars on an estimate like this one.
  • CompareBagging (L6): also trains several models on resampled data — but to average their predictions, not to estimate error.
Wrap-up

Summary: how it all connects
