Lecture 14 · Supplementary slides

Self-attention: every token looks at every other token

Convolutions see a few neighbours; recurrent networks pass information one step at a time. Self-attention lets every position interact directly with every other position in one step: each token asks a query, every token offers a key, the matches become weights, and the output is a weighted mix of values. It is the building block of the Transformer.

Start here

Where self-attention fits in training

Self-attention is a new kind of layer, so it changes the forward pass: three projections, a score for every pair of tokens, a softmax, a weighted sum — all matrix products, all positions in parallel. The loss, back-propagation and the optimizer are unchanged; what does change is the appetite for data and memory.

From L10 and L11

CNNs: local kernels, sharing, equivariance. RNNs: a state updated step by step. Self-attention keeps sharing (the same W for every token) but drops locality and sequential order.

From L4 and L5

Softmax (as a weighting, not an output layer) and back-propagation through matrix products.

New here

Query / key / value, the attention matrix, scaled dot products, path length, the n² cost, permutation equivariance and position encodings.

Self-attention · Motivation

How far must information travel?

To relate the first word of a sentence to the last, an RNN must carry it through every intermediate state, and a CNN needs a stack of layers whose receptive field grows slowly. Self-attention connects any two positions in one step — and computes all pairs at once, with no sequential bottleneck.

\[ \text{RNN: } |i-j| \text{ steps}\qquad \text{CNN: } \Big\lceil \tfrac{|i-j|}{k-1}\Big\rceil \text{ layers}\qquad \text{self-attention: } 1 \]path length between positions i and j

In plain words

  • Think of passing a note across a classroom. RNN: hand it to your neighbour, who hands it on (one step per seat; it gets smudged — vanishing gradients). CNN: each round, everyone can talk to the k − 1 people around them; the note reaches far seats only after several rounds. Self-attention: everyone can talk to everyone at once.
  • Short paths matter for learning: the gradient travels the same path backwards. Long paths are where gradients vanish or explode (L11).
  • They also matter for speed: an RNN cannot compute step t before step t − 1, while every output of a self-attention layer is independent of the others — all tokens run in parallel on a GPU.

Terms on this slide

Long-range dependency
Two far-apart positions whose relation matters (a pronoun and its noun).
Path length
The number of computation steps between two positions.
Receptive field
The set of inputs that can influence one unit (L10).
Sequential bottleneck
Work that must run in order and cannot be parallelized.
Token
One element of the sequence: a word, sub-word or pixel patch.

Calculation, step by step

  1. n = 10 tokens, relate token 2 to token 9: distance 7.
  2. RNN: 7 state updates in order — 7 multiplications by the recurrent Jacobian on the way back.
  3. CNN with k = 3: each layer widens the receptive field by k − 1 = 2, so 7/2 → 4 layers. Self-attention: 1 step, and the 10 × 10 = 100 pairs are all scored at once.

Self-attention · Inputs

From words to a matrix of numbers

A network cannot multiply words. Each token is looked up in an embedding table and becomes a vector of d numbers; the n token vectors are stacked into the input matrix \(\mathbf X\) of shape n × d (“number of tokens × embedding size”). Everything that follows is matrix arithmetic on X.

\[ \mathbf x_i=\mathbf E[\text{token}_i]\in\mathbb R^{d},\qquad \mathbf X=\begin{bmatrix}\mathbf x_1^{\top}\\ \vdots\\ \mathbf x_n^{\top}\end{bmatrix}\in\mathbb R^{n\times d} \]embedding lookup and the input matrix

In plain words

  • The embedding table E has one row per vocabulary word (V rows, d columns). “Looking up” a word just picks its row. The rows are learned — they are weights like any other, updated by back-propagation.
  • In the demo the 4 features are made up and readable (question-ness, verb-ness, noun-ness, function-word-ness) so you can follow the arithmetic. Real embeddings have hundreds of dimensions with no human names.
  • Notice what is missing: nothing in X says where a token sits in the sentence. We will come back to that on the last slide.

Terms on this slide

Embedding
A learned vector that represents a token.
Embedding size d
The number of features per token (4 here; 512–4096 in practice).
Vocabulary V
The set of all tokens the model knows.
n
The number of tokens in the input sequence.
X (n × d)
The matrix whose row i is the embedding of token i.

Calculation, step by step

  1. “How are you doing ?” → n = 5 tokens, d = 4 → X has 5 × 4 = 20 numbers.
  2. Row 3 (“you”) = (0, 0.1, 1, 0): not a question word, barely a verb, a pronoun/noun, not a function word.
  3. With a vocabulary of 50 000 words and d = 512 the table has 50 000 × 512 = 25.6 million learned numbers; each sentence uses n of its rows.

Self-attention · Step 1

Three projections: query, key, value

Each token vector is multiplied by three learned weight matrices to play three roles. The query \(\mathbf q_i\) says what token i is looking for; the key \(\mathbf k_j\) says what token j offers to be matched against; the value \(\mathbf v_j\) is the information token j hands over if it is attended to. The same three matrices are used for every token (parameter sharing).

\[ \mathbf Q=\mathbf X\mathbf W_q\ (n\times d_q)\qquad \mathbf K=\mathbf X\mathbf W_k\ (n\times d_k)\qquad \mathbf V=\mathbf X\mathbf W_v\ (n\times d_v) \]W_q, W_k: d × d_k with d_q = d_k; W_v: d × d_v

In plain words

  • Library analogy: your query is what you type into the catalogue; every book has a key (its index card); the value is the book’s content. Matching queries to keys tells you which contents to read.
  • The query and key must have the same size d_k because they will be dot-multiplied; the value size d_v can differ (it sets the size of the output).
  • In the demo’s hand-designed weights, the “verb” feature feeds query slot 1 and the “noun” feature feeds key slot 1 — so verbs will look for nouns. A trained model discovers such weights by itself; random weights give arbitrary matches.

Terms on this slide

Query q_i
Token i’s “search request”: q_i = x_i W_q.
Key k_j
Token j’s “index card”: k_j = x_j W_k.
Value v_j
Token j’s “content”: v_j = x_j W_v.
W_q, W_k, W_v
The three learned projection matrices (shared by all tokens).
d_k, d_v
Sizes of the query/key vectors and of the value vectors.
Projection
A linear map (matrix product) into a new set of coordinates.

Calculation, step by step

  1. x_are = (0.1, 1, 0, 0.2); W_q columns: (0.4, 1.4, 0, 0.3) and (0.6, 0, 1.2, 0.3).
  2. q_are[1] = 0.1·0.4 + 1·1.4 + 0·0 + 0.2·0.3 = 0.04 + 1.4 + 0 + 0.06 = 1.50.
  3. q_are[2] = 0.1·0.6 + 1·0 + 0·1.2 + 0.2·0.3 = 0.06 + 0 + 0 + 0.06 = 0.12. So q_are = (1.50, 0.12): “are” is looking for a slot-1 (noun) key.

Self-attention · Step 2

Score every query against every key

The score between token i and token j is the dot product \(\mathbf q_i\cdot\mathbf k_j\): large when what i looks for matches what j offers. All n² scores are one matrix product \(\mathbf Q\mathbf K^{\top}\) (n × n). Dividing by \(\sqrt{d_k}\) keeps the numbers in a sensible range so the softmax that follows is not too peaky.

\[ \mathbf S=\frac{\mathbf Q\mathbf K^{\top}}{\sqrt{d_k}}\in\mathbb R^{n\times n},\qquad S_{ij}=\frac{\mathbf q_i\cdot\mathbf k_j}{\sqrt{d_k}} \]the (scaled) attention scores; rows = queries, columns = keys

In plain words

  • A dot product adds up “agreement” coordinate by coordinate: if the query is large in slot 1 and the key is large in slot 1, the score is large. Opposite signs give a negative score.
  • Row i of S is token i’s view of the whole sentence: how much it should care about each other token (including itself).
  • Why √d_k: if the entries of q and k have variance 1, their dot product has variance d_k. Dividing by √d_k brings it back to 1 — otherwise, with d_k = 64 or 512, the scores explode and the softmax becomes almost one-hot (tiny gradients).

Terms on this slide

Dot product
q · k = Σ_m q[m]·k[m]: a measure of alignment.
Attention scores S
The n × n matrix of all query–key matches.
Scaled dot product
The dot product divided by √d_k.
Kᵀ
K transposed (d_k × n), so that QKᵀ is n × n.

Calculation, step by step

  1. q_are = (1.50, 0.12); k_you = x_you W_k = (1.40, 0.14).
  2. q_are · k_you = 1.50 × 1.40 + 0.12 × 0.14 = 2.10 + 0.02 = 2.12.
  3. Scale: 2.12 / √2 = 1.50. Row “are” scaled: How 0.05, are 0.17, you 1.50, doing 0.26, ? 0.25 — “you” stands out.

Self-attention · Step 3

Softmax: scores become weights that sum to one

Apply a softmax to each row of the score matrix. The result \(\mathbf A\) is the matrix of attention weights: every entry is positive and every row sums to 1, so row i says what fraction of its attention token i gives to each token j.

\[ A_{ij}=\operatorname{softmax}_j(S_{i\cdot})=\frac{e^{S_{ij}}}{\sum_{j'=1}^{n}e^{S_{ij'}}},\qquad \sum_j A_{ij}=1 \]row-wise softmax (the “Softmax” bubble in the slide figure)

In plain words

  • Exponentiating makes every score positive and amplifies differences: a score 1.5 above the others gets e^1.5 ≈ 4.5 times more weight. Dividing by the sum turns the row into shares of 100 %.
  • Large scores → one token takes almost all the weight (a hard choice). Tiny scores → everyone gets the same share (no choice at all). The √d_k scaling keeps us in between.
  • This is the same softmax as the output layer of L4, used here not to predict a class but to weight the tokens.

Terms on this slide

Softmax
exp of each entry divided by the sum of exps.
Attention weights A (n × n)
Row-normalized scores; A_ij = how much i attends to j.
Row-wise
Applied separately to each row (each query).
Peaky / uniform
Weights concentrated on one token / spread evenly.
Entropy
A measure of how spread out the weights are (0 = one-hot, ln n = uniform).

Calculation, step by step

  1. Row “are”: scores (0.05, 0.17, 1.50, 0.26, 0.25).
  2. Exponentials: e^0.05 = 1.05, e^0.17 = 1.18, e^1.50 = 4.47, e^0.26 = 1.30, e^0.25 = 1.29; sum = 9.29.
  3. Weights: 1.05/9.29 = 0.11, 0.13, 0.48, 0.14, 0.14 — they add up to 1.00; nearly half of “are”’s attention goes to “you”.

Self-attention · Step 4

The output: a weighted mix of the values

The new representation of token i is the weighted sum of all values: \(\mathbf z_i=\sum_j A_{ij}\mathbf v_j\). In matrix form the whole layer’s output is \(\mathbf Z=\mathbf A\mathbf V\) (n × d_v) — the “hidden states” in the slide figure. Each token has absorbed information from the tokens it attended to.

\[ \mathbf z_i=\sum_{j=1}^{n}A_{ij}\,\mathbf v_j\qquad\Longleftrightarrow\qquad \mathbf Z=\mathbf A\mathbf V\in\mathbb R^{n\times d_v} \]attention output \[ \operatorname{Attention}(\mathbf Q,\mathbf K,\mathbf V)=\operatorname{softmax}\!\Big(\frac{\mathbf Q\mathbf K^{\top}}{\sqrt{d_k}}\Big)\mathbf V \]the whole layer in one line (scaled dot-product attention)

In plain words

  • Because the weights sum to 1, z_i is an average of value vectors — it stays in the range of the values; it is just which values dominate that changes from token to token.
  • If “are” attends 48 % to “you”, then z_are is about half “you”’s value plus smaller shares of the others: the verb now “knows” its subject.
  • Stacking several such layers (with small feedforward networks in between) lets information combine over and over — that is a Transformer encoder.

Terms on this slide

z_i
The output (new representation) of token i.
Z = AV (n × d_v)
All outputs at once: attention weights times values.
Weighted sum / convex combination
Σ_j a_j v_j with a_j ≥ 0 and Σ a_j = 1.
Hidden state
The representation passed to the next layer.

Calculation, step by step

  1. Values (3 numbers each): v_How = (1, 0.1, 0), v_are = (0.16, 1.06, 0.06), v_you = (0, 0.1, 1), v_doing = (0.2, 0.9, 0.1), v_? = (0.9, 0.3, 0.3).
  2. Weights of “are”: (0.11, 0.13, 0.48, 0.14, 0.14). First output number: 0.11·1 + 0.13·0.16 + 0.48·0 + 0.14·0.2 + 0.14·0.9 = 0.11 + 0.02 + 0 + 0.03 + 0.13 = 0.29.
  3. Likewise z_are ≈ (0.29, 0.36, 0.54): the third number is large because “you”’s value is (0, 0.1, 1) and “you” got the most weight.

Self-attention · All steps

The whole pipeline on one sentence

Embeddings → three projections → scores → softmax → weighted sum. Five steps, all differentiable matrix operations, so back-propagation trains the embeddings and \(\mathbf W_q,\mathbf W_k,\mathbf W_v\) like any other weights. The attention map \(\mathbf A\) is also a window into what the model “looks at”.

\[ \mathbf X\ \xrightarrow{\ \mathbf W_q,\mathbf W_k,\mathbf W_v\ }\ \mathbf Q,\mathbf K,\mathbf V\ \xrightarrow{\ \mathbf Q\mathbf K^{\top}/\sqrt{d_k}\ }\ \mathbf S\ \xrightarrow{\ \text{softmax}\ }\ \mathbf A\ \xrightarrow{\ \cdot\,\mathbf V\ }\ \mathbf Z \]the slide figure as a formula chain

In plain words

  • Read the attention map row by row: row “doing” shows which tokens the verb “doing” pulls information from. With the designed weights it is mostly “you” — the subject.
  • With random weights the map is arbitrary: an untrained model attends to nothing in particular. Training changes the weights until useful tokens match.
  • Real models run several attention maps in parallel (“multi-head”) so different heads can track different relations (subject–verb, adjective–noun, …), then concatenate the outputs. The arithmetic of each head is exactly what you see here.

Terms on this slide

Attention map
The matrix A drawn as a heat map (rows = queries).
Self-attention
Queries, keys and values all come from the same sequence X.
Head
One set of W_q, W_k, W_v; models use several in parallel.
Differentiable
Has derivatives everywhere, so gradients can flow through it.

Calculation, step by step

  1. Parameters of one head with d = 4, d_k = 2, d_v = 3: W_q 4×2 = 8, W_k 8, W_v 4×3 = 12 → 28 numbers (plus the embedding table). The count does not depend on n.
  2. Work for n = 5: Q, K, V cost 5×4×(2+2+3) = 140 multiplications; QKᵀ 5×5×2 = 50; AV 5×5×3 = 75.
  3. Back-propagation reverses each step: ∂J/∂V = Aᵀ ∂J/∂Z, ∂J/∂A = (∂J/∂Z) Vᵀ, then through the softmax and the two projections — all standard matrix calculus.

Self-attention · Cost

What a layer costs: self-attention vs. recurrent vs. convolutional

Self-attention costs O(n²·d) per layer because every pair of tokens is scored — quadratic in the sequence length, but with O(1) sequential operations and O(1) path length. A recurrent layer costs O(n·d²) but needs n sequential steps; a convolutional layer costs O(k·n·d²) and needs O(log_k n) layers to connect distant positions.

\[ \begin{array}{lccc} & \text{per layer} & \text{sequential ops} & \text{max path} \\ \text{self-attention} & O(n^2 d) & O(1) & O(1)\\ \text{recurrent} & O(n d^2) & O(n) & O(n)\\ \text{convolutional} & O(k\,n\,d^2) & O(1) & O(\log_k n) \end{array} \]the standard comparison (Vaswani et al., 2017, Table 1)

In plain words

  • Where does n² come from? The score matrix has n rows and n columns, each entry a d_k-dimensional dot product. For a 1 000-token document that is a million scores per head per layer — and they must be stored for the softmax and for back-propagation: the “memory cost” in the slide’s table.
  • When n < d (typical sentences, d in the hundreds) self-attention is actually cheaper per layer than a recurrent layer — and it runs in parallel. When n ≫ d (long documents, high-resolution images) the n² term bites.
  • The sequential-operations column is about wall-clock time on a GPU: O(n) sequential steps cannot be parallelized, O(1) can.

Terms on this slide

Complexity per layer
How the number of multiplications grows with n, d, k.
Sequential operations
Steps that must wait for the previous one.
Maximum path length
Longest distance information must travel between two positions.
Memory cost
Here: storing the n × n attention matrix for every head and layer.
O(·)

Calculation, step by step

  1. n = 128 tokens, d = 256: n²d = 16 384 × 256 = 4.2 M; nd² = 128 × 65 536 = 8.4 M; knd² (k = 3) = 25.2 M. Self-attention is the cheapest.
  2. n = 4 096, d = 512: n²d = 8.6 G; nd² = 1.07 G. Now self-attention is 8× more expensive — and the attention matrix alone has 16.8 M entries per head and layer.
  3. Path length for n = 4 096: RNN 4 096 steps; CNN with k = 3 needs log₃ 4 096 ≈ 8 layers; self-attention 1.

Self-attention · The comparison table

CNN vs. RNN vs. self-attention

Each architecture encodes a different assumption. CNN: locality and translation equivariance. RNN: sequential state shared over steps. Self-attention: pairwise query–key–value interactions with no locality at all — which gives direct long-range interactions and full parallelism, at the price of n² cost and a hunger for data (fewer built-in assumptions means more must be learned).

In plain words

  • CNN: local sliding kernels; sparse interactions, parameter sharing, equivariance. ✓ highly parallel, compact parameters. ✗ long-range dependencies need many layers.
  • RNN: step-by-step state update with shared transition weights. ✓ any length, can in principle carry global context, reuses one unit. ✗ sequential training bottleneck, vanishing/exploding gradients.
  • Self-attention: pairwise Q–K–V interactions. ✓ direct interaction between any two inputs, fully parallelizable. ✗ computational and memory cost, requires massive training datasets.
  • The last point is the no-free-lunch theorem of L1 in action: the convolutional prior is a gift when it is true (images); attention gives it up and must learn the structure from data instead.

Terms on this slide

Characteristic
What the layer computes and assumes.
Translation equivariance
Shift the input → the output shifts the same way (L10).
Transition weights
The RNN’s hidden-to-hidden matrix W (L11).
Parallelizable
Computable for all positions at the same time.
Inductive bias / prior
Assumptions built into the architecture (L1, L10).

Calculation, step by step

  1. Parameters for d = 512: one 3-wide 1-D conv layer 3 × 512 × 512 = 0.8 M; one RNN step 512 × 512 (W) + 512 × 512 (U) = 0.5 M; one attention head with d_k = d_v = 64: 3 × 512 × 64 = 0.1 M (8 heads: 0.8 M). Comparable — the difference is not the parameter count.
  2. Time for n = 512 tokens on a parallel machine: attention and CNN ≈ 1 round each; RNN 512 rounds.
  3. Data: with no locality prior, attention must learn from examples that “nearby words matter” — that is why it shines when training sets are huge.

Self-attention · Beyond the slide

Self-attention ignores order — so position must be added

Nothing in \(\operatorname{softmax}(\mathbf Q\mathbf K^{\top}/\sqrt{d_k})\mathbf V\) depends on the index i or j — only on the vectors. Shuffle the tokens and every token gets exactly the same output, just shuffled along (permutation equivariance). To know that “How” came first, a position vector is added to each embedding before the projections.

\[ \mathbf Z(\mathbf P\mathbf X)=\mathbf P\,\mathbf Z(\mathbf X)\quad\text{for any permutation matrix }\mathbf P \]permutation equivariance of a self-attention layer \[ \mathbf x_i\leftarrow \mathbf x_i+\mathbf p_i \]position encoding: add a vector that depends on i (sinusoidal or learned)

In plain words

  • An RNN knows order because it reads left to right; a CNN knows relative position because the kernel has a left and a right. Self-attention is a set operation: a bag of tokens.
  • “Dog bites man” and “man bites dog” would get identical token outputs. Adding a position vector to each embedding makes “dog at position 1” a different vector from “dog at position 3”, and the attention can use that.
  • This is not in the slide’s figures, but it is the reason Transformers add position encodings — and it shows that the table’s “pairwise interactions” are between vectors, not between positions.

Terms on this slide

Permutation
A reordering of the tokens.
Permutation equivariance
Reordering the input reorders the output identically.
Position encoding p_i
A vector that depends only on the position i, added to x_i.
Set vs. sequence
A set has no order; a sequence does.

Calculation, step by step

  1. Without positions, shuffle “How are you doing ?” to “you doing How ? are”: the output row for “you” is the same vector as before — only its row number changed. Largest change in any output: 0.000.
  2. With position vectors, “you” at position 3 has x = (0, 0.1, 1, 0) + p₃ and at position 1 it has x + p₁ ≠ x + p₃: its query, key and value change, and so do all outputs.
  3. Check in the demo: the “largest change” statistic is exactly 0 without positions and clearly positive with them.

Wrap-up

Summary: how it all connects

Self-attention = project each token into a query, a key and a value; score every pair with a scaled dot product; softmax each row into weights; mix the values. One step between any two positions, everything in parallel, at a cost of n² — and with no notion of order unless you add one.

StepFormulaShapeMeaning
Embed\(\mathbf X=[\mathbf x_1;\dots;\mathbf x_n]\)n × dtokens as vectors
Project\(\mathbf Q=\mathbf X\mathbf W_q,\ \mathbf K=\mathbf X\mathbf W_k,\ \mathbf V=\mathbf X\mathbf W_v\)n × d_k, n × d_k, n × d_vwhat I seek · what I offer · what I give
Score\(\mathbf S=\mathbf Q\mathbf K^{\top}/\sqrt{d_k}\)n × nmatch of every query with every key
Weight\(\mathbf A=\operatorname{softmax}_{\text{rows}}(\mathbf S)\)n × n, rows sum to 1share of attention
Mix\(\mathbf Z=\mathbf A\mathbf V\)n × d_vnew token representations
Cost\(O(n^2d)\), O(1) sequential, path 1—vs. RNN O(nd²), n sequential, path n
Order\(\mathbf x_i+\mathbf p_i\)n × dposition must be added explicitly

Remember

Attention(Q, K, V) = softmax(QKᵀ/√d_k) V. Every token’s output is an average of all values, weighted by how well its query matches their keys.
